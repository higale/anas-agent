# 插件示例

先构建并启动 Anas，在“设置 > 插件”点击“安装插件”，选择下面某个子目录中的 `PLUGIN.json`，或选择打包好的插件 ZIP。选择清单时会复制整个插件目录。示例无需安装 npm 依赖，也不会默认安装到用户数据目录。

- `notepad/`：中英文记事本，无需后台；演示语言包、跟随宿主语言、数据保存和未保存状态保留。
- `backend-demo/`：纯英文的可选 Node 后台示例，首次点击“Call”才启动后台；可测试正常结果、错误返回和停止后重启。

记事本在清单中声明 `"lang": "lang"`，通过 `anas.getLanguageResources()` 读取 `lang/en.json`、`lang/zh-CN.json`，通过 `anas.getInfo()` 获取宿主语言。`plugin.name` 和 `plugin.description` 同时用于宿主菜单、设置及默认窗口标题；页面在聚焦时及可见期间每 5 秒刷新语言、主题和字号，保留草稿及保存状态。缺失或空白文案回退英文。

为保持免构建示例简洁，`app.js` 只演示静态文案查表；需要插值、复数等功能时使用插件自己的 i18next 实例。新增语种可复制英文 JSON 修改文本，宿主也需有对应语种，详见[多语言接口](../../docs/PLUGINS.md#多语言)。

安装会复制产物，修改源码后需卸载再重新安装同 ID；保存数据会保留。插件接口、清单和生命周期见[插件文档](../../docs/PLUGINS.md)。
