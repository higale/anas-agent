# 存储回归样本

- `native-repair-*` 是会话数据库 v3 的冻结目录，用于当前格式的版本字段修复、文件修改归档和失败保全测试。测试直接恢复原生数据，不调用迁移器。四份样本由原冻结数据离线制作后固定，v3 样本离线增加组标题、成员归属和按范围修订索引，逐表核对既有执行及资源记录完全一致；清单记录上一份 v2 样本哈希，不改变执行记录；来源和哈希记录在对应 JSON 中，原转换代码已移除。公开前将 Windows 测试路径中的用户名统一为 `user`；保留脱敏前哈希，重算受影响的定义哈希及引用，并逐表核对其余内容、身份和恢复状态不变。
- `legacy-catalog`、`legacy-conversation` 仅用于验证旧执行格式被拒绝且原始字节不变，不提供旧库读取或升级能力。
- 清单记录解压字节数及 SHA-256。测试加载时校验；禁止为了通过测试修改来源数据、忽略哈希或跳过失败边界。
