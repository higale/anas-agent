# 供应商图标 / Provider icons

图标嵌入 `data/config/model-templates.json`，以 Base64 SVG 保存。品牌标识属于各自权利人，用于识别对应服务。
Icons are embedded as Base64 SVG in `data/config/model-templates.json`. Brand marks belong to their respective owners and identify the corresponding services.

LobeHub 图标采用 MIT（见 `lobe-LICENSE`）；Ollama 采用 MIT（见 `ollama-LICENSE`）。LM Studio 和 vLLM 使用官方品牌资源；LLaMA 模板使用 Llama 官网的标识。
LobeHub icons use MIT (see `lobe-LICENSE`); Ollama uses MIT (see `ollama-LICENSE`). LM Studio and vLLM use their official brand assets; the LLaMA templates use the mark from the Llama website.

单色图标添加了深浅主题样式；Ollama、Kimi 和 Llama 字形的固定填充改为跟随该样式。SVG 已清理冗余元数据并精简可等价优化的路径，保留品牌颜色、渐变和动态主题样式。
Monochrome icons include light/dark theme styles; fixed glyph fills in Ollama, Kimi, and Llama follow those styles. SVGs have redundant metadata removed and equivalent paths simplified, preserving brand colors, gradients, and dynamic theme styles.
