# Anas 技能手册

语言：[English](./AGENT_SKILLS.en.md) | [中文](./AGENT_SKILLS.zh-CN.md) · [返回用户手册](./USER_GUIDE.zh-CN.md)

技能是一组供 Agent 按需读取的操作说明，可附带脚本和参考资料。启用技能不会自动安装依赖或开启工具权限。

## 添加与管理

在“设置 > 技能”中管理全局来源，浏览技能说明和文件。点击分组名称在右侧查看技能列表，点击前方的方框箭头展开或收起。分组标题旁显示 `@别名`；外部目录的显示名称和别名在回车或失焦时保存。文本和脚本支持语法高亮，点击“编辑”后可修改并手动保存；系统及插件技能文件只读。保存会检查外部修改冲突，放弃未保存修改前会提示。点击来源目录、技能或文件的标题可在文件管理器中定位，“技能位置”也支持点击。

Markdown 文件默认显示排版预览，可切换“源码”；顶部元数据折叠展示。相对图片按文件所在目录加载，本页链接跳转到对应标题，其他本地文件链接在文件管理器中定位。

- **导入技能**：点击页面顶部“导入技能”，选择一个或多个包含 `SKILL.md` 的技能目录，复制到应用数据目录的 `skills/`；重名时不导入、不覆盖。选择窗口默认打开示例目录。成功后自动展开“用户”分组并定位到首个导入的技能。
- **添加目录**（右上方）：选择包含多个技能子目录的外部目录，直接引用其中的文件，不复制。外部来源可改名、设置快捷别名、排序或移除；移除只删除引用，不删除文件。
- **项目技能**：点击项目设置“能力 > 技能”标题旁的加号添加自定义 skills 总目录。目录以“项目 - 目录名”与其他来源并列显示。不再自动扫描源文件夹的 `.agents/skills/`，继续使用该目录时需手动添加。来源按目录分组，支持打开目录及移除自定义引用，随项目设置保存；只在对应项目的能力列表和会话中使用，不出现在全局技能页。

`~/.agents/skills` 是默认外部来源，可以移除。修改文件后，点击刷新重新读取；无法读取的技能会显示错误。

选中外部目录后，通过左侧按钮区上移、下移或移除目录引用。技能条目暂不支持删除和排序，选中条目或文件时这些按钮禁用。

项目技能在“能力 > 技能”中按“项目 - 目录名”分组，与其他来源并列显示。每项使用普通复选框，一行可排列多个条目；选中同时启用快捷方式和模型用途。仅最顶层“技能”可展开或收起，内部来源和目录直接显示。添加目录按钮位于最外层“技能”标题旁，打开和移除引用按钮位于目录标题旁。修改随项目保存，取消不会写入。

## 谁可以使用

技能详情按“快捷方式、模型可用”排列，分别控制两种用法：

- **快捷方式**：可在消息输入框用 `/技能名 用户需求` 主动调用；输入 `/` 可查看候选。Anas 将完整 `SKILL.md` 原文及来源路径直接发送给模型，调用后的文字作为独立的用户需求，可展开会话中的技能记录查看实际发送内容。
- **模型可用**：向 Agent 提供名称、用途和 `SKILL.md` 绝对路径，让它按任务需要读取说明。

两项都关闭时，列表右侧显示“已停用”，仍可查看和编辑；普通技能只关闭其中一项不会标为停用。插件技能还受自身贡献开关和依赖工具限制；它们停用时，用途复选框保留保存的选择并允许修改，实际技能仍需重新启用相关能力后才能使用。加载失败单独显示“错误”，不使用删除线。

项目和子 Agent 的技能只选择启用或停用，不再分别定制快捷方式和模型用途。普通技能选中后遵循技能页的全局用途设置；项目技能选中后同时启用快捷方式和模型用途。子 Agent 只使用模型用途。全局停用或加载失败的技能不会因局部勾选而变得可用。插件技能随所属插件整体选择。

子 Agent 只配置模型使用范围，可单独启用“项目技能”，并遵循项目的“限制子 Agent 能力”设置。项目中的授权不会把子 Agent 自带技能加入主会话；这些技能仅供所属 Agent 的模型使用，不提供快捷入口。移除子 Agent 不影响普通技能的快捷调用，也不会因未使用的自带技能阻断已有任务恢复；确实依赖已删除技能时仍会报错。详见[子 Agent](./USER_GUIDE.zh-CN.md#子-agent)。

同名技能分别按快捷方式、模型的有效选择确定优先项：项目手动引用目录顺序 → 用户 → 外部目录顺序 → 系统 → 插件（按插件 ID 排序）。`/name` 使用优先项；`/name@alias` 可指定来源，例如 `/name@user`、`/proofread@plugin:writing-helper`。外部来源的别名可在技能页修改。同一目录被多个来源引用时，各来源的选择和别名保持独立，仍按有效选择决定优先项。

## 脚本执行

技能脚本使用现有 Shell 工具，遵循当前对话权限：严格审批下按普通命令审核，智能审批下由现有只读检查与模型判断决定，完全访问跳过执行前审核。启用技能不会开启已关闭的“执行命令”或扩大工具范围。

全局、单技能和项目级脚本免审已移除，旧免审设置不再生效；技能文件和快捷、模型选择不受影响。此前依赖技能豁免而尚未执行的调用需要按当前权限重新提交。

## 系统技能与示例

系统技能位于应用数据目录的 `skills/_system/`，随程序提供：

| 技能 | 用途 |
| --- | --- |
| `config` | 修改应用设置和头像，依赖“修改配置”能力。 |
| `skill-manager` | 创建、修改技能，或从本地目录、Git 仓库安装技能；依赖文件读写，远程安装还需 Git 和网络，测试脚本还需相应运行环境。 |
| `tool-manager` | 创建、修改和排查 Anas 自定义工具，包含格式参考和 Python 示例模板；依赖文件读写，测试还需命令执行和对应运行环境。 |

`examples/skills/` 只存放示例，默认不加载。可用“导入技能”复制到“用户”后再使用：

| 示例 | 用途与主要依赖 |
| --- | --- |
| `weather` | 天气查询；Python 3 和可访问 wttr.in 的网络。 |
| `ip-location` | 公网 IP 与粗略归属地；Python 3.8+ 和可访问 ipinfo.io 的网络。 |

系统技能在启动时从程序内置文件刷新。`examples/` 在启动及恢复备份时连同说明文件、技能、工具、插件及子 Agent 示例整体更新。需要修改时，先导入到“用户”或复制到项目技能目录。

## 运行前的准备

- 查看技能的环境要求，以及随技能提供的 `SETUP.md`（如有）。Anas 不会因勾选技能而自动安装 Python、Git、ExifTool 等程序。
- 在“设置 > 环境”中编辑应用 `.env`。命令要读取其中的变量，还需开启相应 Agent 的“.env”能力。模型名称、账号和服务权限按实际使用的服务配置。
- 主动调用会直接加载完整 `SKILL.md`；模型自主加载技能或读取附带资料仍需要文件读取工具或执行命令，运行脚本通常需要“执行命令”。使用工具的模型需支持并开启“工具调用”，执行时沿用当前授权模式。

## 编写技能

Anas 使用 [Agent Skills 格式](https://agentskills.io/specification)。每个技能目录必须包含名称完全大写的 `SKILL.md`，还可包含 `scripts/`、`references/`、`assets/` 等资源。

例如 `photo-search/SKILL.md`：

```markdown
---
name: photo-search
description: 按照片元数据搜索本地照片；不用于识别画面内容。
compatibility: 需要 Python 3 和 ExifTool。
---

在此编写执行步骤、参数和结果说明。
```

- `name` 必须与目录名一致，使用小写英文字母、数字和单个连字符，最长 64 字符，首尾不能是连字符。
- `description` 必填，说明用途及适用场景。Agent Skills 规范要求最长 1024 字符；Anas 对超长描述显示叹号警告，保留完整内容，仍允许加载、导入、保存、模型使用和快捷调用。缺失或空描述仍按错误处理。
- `compatibility` 可选，填写时不能为空，最长 500 字符，用于说明环境依赖。
- 相对路径以 `SKILL.md` 所在目录为基准。需要用户提前准备的内容可放在 `SETUP.md`。
- 主动调用保留文件头和正文原文，不替换 `$ARGUMENTS`、`$0` 等占位符。技能应说明如何根据用户需求执行任务；`SKILL.md` 最多 1 MiB。

模型和用户的可用开关保存在 Anas 配置中，不写入技能文件。
