# Anas 用户手册

语言：[English](./USER_GUIDE.en.md) | [中文](./USER_GUIDE.zh-CN.md)

GitHub：[higale/anas-agent](https://github.com/higale/anas-agent) · 开源协议：[MIT](https://github.com/higale/anas-agent/blob/main/LICENSE)

Anas 是一个本地桌面 Agent。你可以为不同项目配置上下文、工具、技能和子 Agent。配置、会话和记忆保存在本地；完成任务所需的内容会发送给你配置的模型服务。

在左下角菜单选择“帮助”，即可在右侧工作区阅读手册。用“目录”跳转章节，点击文内链接打开相关手册；关闭、放大或切换标签不影响聊天。

## 快速开始

1. 在“设置 > 模型”中添加模型服务，填写地址、模型名和密钥。
2. 在消息输入框底部的工具栏中选择模型。
3. 输入消息并发送；需要时可添加附件或选择项目。

新会话依次使用项目指定模型、全局默认模型、新建前选中的模型；均不可用时保持未选择，需手动选择后发送。项目模型使用项目指定的推理选项，默认模型使用自身默认推理选项，沿用上个模型时保留其推理选项。已有会话和恢复的草稿保留原选择。项目的完整提示词和请求预览按同一顺序选择模型。

工具执行期间，工具调用标题整行显示连续流光，包含图标、工具名、说明、状态标记和操作入口，不影响点击或展开。等待用户确认或回答、调用结束后停止；系统启用“减少动态效果”时显示普通文字。

在“设置 → 通用 → 外观”的主题行，可选择系统、浅色或深色，并通过“标题栏图标”控制主题快捷入口，默认显示。左键点击聊天标题栏菜单图标左侧的主题图标，会根据当前实际外观在浅色和深色之间切换；右键菜单可选择系统、浅色或深色，每次自动保存。系统模式下左键切换会改为固定浅色或深色，右键选择“系统”可恢复自动跟随。

## 项目与能力

新建和编辑项目时，名称留空会自动使用“未命名项目1、2、3…”中尚未占用的名称。工作目录可以留空，使用时跟随“设置 → 对话 → 项目默认目录”，未配置时使用系统“文档”目录；项目文件保持空列表，不保存解析后的默认路径。

项目和子 Agent 设置仅保留最顶层能力分组的展开和收起，标题显示已选数／总数。内部来源和目录直接显示，不再有下拉箭头；点击条目名称切换复选框。定制模式下，主分组和子分组标题旁始终显示一个批量选择图标（主分组收起时也可使用）：未全选时点击全选，已全选时点击全不选，只修改本组可选条目。列表随内容自然增高，内容较多时滚动设置区域。项目技能和工具目录以“项目 - 目录名”与其他来源并列；自定义工具和技能内部只保留项目区上方的分割线，整个自定义工具区上方也有分割线。添加目录按钮位于顶层“技能”和“自定义工具”标题旁，收起时也可使用；打开目录和移除引用按钮保留在目录标题旁。悬停目录名称查看完整路径，失效目录保留错误信息。

点击“能力 > 技能”和“能力 > 自定义工具”标题旁的加号可添加多个总目录，目录内应包含各技能或工具包的子目录。引用仅对当前项目生效，不复制文件，也不增加项目工作目录或写入权限。添加和移除随项目设置保存，取消编辑不会生效；移除只解除引用。空目录及失效目录保留，失效目录显示错误并可移除。不同来源保留独立选择，同名资源按项目目录顺序优先。外部文件需另行备份。项目不再自动发现源文件夹中的 `.agents/skills/`、`.agents/tools/`；已有文件不删除，继续使用时请手动添加对应总目录，并在能力列表中核对勾选。

侧栏依次显示置顶项目、项目和独立的默认项目。拖动项目名称可在所属分组内排序，拖动对话名称可在所属项目内排序；置顶与未置顶条目分别排序，不支持跨组移动。松开鼠标保存顺序，按 Esc 取消。手动排序后，新条目排在未置顶条目前，消息更新不会打乱已保存的顺序；默认项目固定在最后。

所有项目使用相同设置。原简易对话项目正常读取，已有名称、提示词、模型选择和对话保留；缺失设置按普通项目默认值生效，能力默认全开、编码模式默认关闭，缺少项目路径时使用全局项目默认目录（未配置时为系统文档目录）。可在项目设置中手动关闭不需要的能力。

项目编辑窗口直接提供项目提示词、上下文、工具、技能和子 Agent 设置。新项目默认使用全部可用能力，各项可独立调整，无需开启总开关。已有项目直接使用保存的选择和提示词，不自动转换或重置旧配置。设置页只管理各来源的启用范围，不再提供默认能力页。“编码模式”独立控制开发工作方式，不会提高授权范围。

默认项目名称不可修改，其他设置与普通项目相同，包括图标、颜色、工作目录、权限模式、模型及推理选项、编码模式和能力选择。未选择工作目录时跟随全局项目默认目录；已保存的目录选择保持不变。项目提示词、压缩提示词和能力选择均可直接编辑并生效。

点击项目图标可选择内置图标或上传图片。项目和供应商共用图片导入规则：位图居中裁方，最大 128 × 128 像素，小图不放大；SVG 保留矢量格式。选择内置图标即可切回，点击保存后生效。

- “文件读”和“文件写”可展开逐项选择，也可通过分组开关全选或取消。已删除或不可用的已选项仍可取消。
- 下文列出的工具都需要模型支持并开启“工具调用”。上下文类能力不需要工具调用；技能的实际使用还取决于读取文件和执行任务所需的工具。
- 能力选择决定提供什么工具，授权模式决定执行具体操作时是否需要确认。关闭“文件读”“文件写”或“网络访问”只撤下对应工具；执行命令和 MCP 仍可能提供同类操作。
- 修改只影响之后启动的任务；已经运行或等待恢复的任务继续使用启动时的选择。

项目和子 Agent 的自定义工具、MCP、插件、子 Agent、技能条目统一使用普通复选框，一行排列多个条目，不显示条目图标。停用或不可用条目以警示色显示，具体原因放在 tooltip 中，不附加状态文字。分组标题显示已选数／总数。最外层资源分组保留“全部／定制／关闭”，切换全部或关闭不清空定制选择。MCP 按服务整体选择工具可用性，插件按整个插件选择贡献；最终条目不再提供模式或内部细选。勾选不绕过全局停用、加载错误、依赖条件和项目限制。

默认包含新增的可用 MCP 服务和插件；明确使用限定来源的配置时，未选中的新来源保持关闭。切换最外层分组模式保留定制名单；直接修改最终条目会将该分组切换为“定制”。MCP 无法获取完整列表时，仍可取消已保存的服务。

普通技能选中后按全局设置启用快捷方式和模型用途；项目技能选中后两种用途都启用。子 Agent 仅使用模型用途。全局停用的用途不生效，局部勾选状态可以保留。

- **全开**：启用内置能力，将 MCP、插件及其他总分组设为“全部”，并取消项目的“限制子 Agent 能力”。仍遵守各来源的全局启用范围。
- **全关**：关闭各项能力；保留 MCP、插件、自定义工具、技能和子 Agent 的定制选择。

在“设置 > 工具”左侧选择“内置工具”或“MCP”，右侧分别按能力或服务器分组；点击工具名查看参数和完整说明。横线下方通过目录树浏览自定义工具及包内文件。

项目技能在项目设置“能力 > 技能”中按“项目 - 目录名”分组，与其他来源并列显示。勾选技能同时启用快捷方式和模型用途；目录管理与勾选独立。修改随项目保存，取消不会写入。

### 编码模式

“编码模式”独立于能力选择。它加入先读代码、保护已有修改、验证结果等开发规范，并使用保留文件修改、测试证据和待办事项的压缩摘要。模型、工具和访问权限仍按各自设置生效。

应用自动读取适用的 AGENTS 规则全文，并直接加入系统上下文，无需模型先调用读取工具。同目录优先使用 `AGENTS.override.md`，不存在时使用 `AGENTS.md`；更深目录规则只适用于对应目录树。规则占用输入 token，每次运行保留已检查目录的快照。

初始加载主工作目录适用的规则，其他目录按结构化文件操作的目标路径发现。如果写入依赖尚未告知模型的新规则，会先返回“未执行”，让模型看到规则后重新决定。任意 Shell 命令、未声明文件目标的 MCP 或自定义工具不会自动检查全部受影响路径。

普通工作区项目的提示词区域提供“项目提示词”和“压缩提示词”两个标签。压缩提示词留空使用当前模式的内置默认；点击“载入默认”可在默认全文上修改。非空内容完整替换默认，清空恢复默认，修改随项目保存或取消。两项提示词均可直接编辑，随项目保存后生效。自定义压缩仅用于主会话；子 Agent 使用内置模板。切换编码模式不会覆盖已有自定义文本。

自定义压缩提示词最多 50,000 字符，必须且仅保留一个 `{conversation}` 占位符，`{output_language}` 可选。自动和手动压缩共用该模板；已有任务及其恢复使用启动时的自定义内容。

左侧标题区菜单可查看“完整提示词”“压缩提示词”和“预览请求”。压缩提示词预览只读展示当前草稿生效的内容：自定义为空时显示内置默认，否则显示自定义全文。预览不会提前包含未来操作才发现的子目录规则。

### 资料

向 Agent 提供“设置 > 通用”中的助手名称和角色设定。旧配置保存的自定义指令保留在设置文件中。需要继续使用的内容可手动复制到角色设定。启用“修改配置”后，Agent 可按要求修改助手名称、角色和头像。称呼、回答风格等偏好使用所选记忆方式保存，跨项目偏好可在“设置 > 记忆”查看和编辑。原用户资料保留在配置中，不注入对话，也不自动导入记忆。子 Agent 是否接收助手资料由自身能力及项目限制决定。

### 运行环境

向 Agent 提供在“设置 > 环境”中选中的系统、日期、目录、命令环境和自定义环境信息。此项只提供说明，不会安装程序或开启执行权限。

项目和子 Agent 开启“运行环境”后，按全局的“内置 rg”提供搜索命令说明。关闭命令执行后，模型仍可看到这些说明。配置方法见[运行环境与环境变量](#运行环境与环境变量)。

### 项目信息

向 Agent 提供当前项目名称、源文件夹及路径使用说明，没有独立工具。关闭后，项目源文件夹仍作为工作目录和授权判断的依据；项目提示词独立控制，不随此项关闭。

### .env

决定执行命令和自定义工具时是否额外加载应用数据目录 `.env` 中的变量。文件在“设置 > 环境”中编辑。

此项没有独立工具。关闭后仍保留系统继承的环境变量，不清空 `.env` 文件，也不改变模型连接或共享 MCP 服务自身的配置。

### 后台工具

允许耗时的内置、自定义或 MCP 工具调用转到后台，让 Agent 查看、等待或取消。以下工具相互依赖，作为一组启停，不能逐个选择。关闭后，新调用等待完成再返回；已开始的调用不会因此取消。

| 工具 | 功能 |
| --- | --- |
| `read_call` | 查看本会话后台调用的状态、进度和终端信息。 |
| `read_call_output` | 按段读取后台调用的输出和结果。 |
| `wait_call` | 等待指定调用结束或等待超时。 |
| `cancel_call` | 请求取消指定后台调用。 |
| `write_call` | 向交互式终端发送文本、按键或调整尺寸。 |

`write_call` 需要启用“执行命令”或选中的交互式自定义工具。终端必须在启动时创建，不能事后给普通命令补接输入。子 Agent 的后台任务由“子 Agent”能力单独管理。

工具繁忙时会自动排队，无需重复提交。等待或执行较久的调用会返回编号，供 Agent 查看后续结果。

### 计划

提供 `write_todos`，让 Agent 建立和更新当前任务的计划及完成状态。适合多步骤任务；计划本身不执行命令或修改文件，实际工作仍需对应能力。

### 执行命令

让 Agent 通过系统命令运行程序、脚本、搜索、测试和构建。工具按实际命令程序命名，例如 macOS 的 `zsh`、Windows 的 `pwsh` 或 `powershell`；需要系统中存在可用的命令程序。

内置 rg 可用于文件和文本搜索，无需另行安装。Python、Node.js 等运行时按需自行准备。后续终端输入还需要“后台工具”；应用 `.env` 变量由 `.env` 能力独立控制。命令执行遵循当前对话的授权模式。

执行命令只管理直接启动的 Shell。Shell 正常退出即完成调用；取消、超时和退出 Anas 只停止 Shell，其子进程由模型或用户显式停止。启用后台工具时，长命令返回调用编号后可跨轮继续，停止回答不会取消已交接的 Shell。模型使用 `read_call`／`wait_call` 查看状态，使用 `cancel_call` 停止仍运行的 Shell；已完成调用不能借此停止子进程。完成结果直接列出已识别的存活直接子进程。

工作区菜单中，“项目记忆”下方的“进程列表”在右侧显示当前对话的 Shell 及其直接启动的进程，不包含应用内部再启动的后代进程，支持自动刷新、手动刷新和逐个终止。列表只包含已识别的关联；系统代启或复用的应用可能不在其中。手动终止会核验进程身份，只操作选中进程。交互式终端关闭时，仍连接终端的程序可能因操作系统的关闭／挂断行为退出。

Windows 和 macOS 的 Shell 成功、有完整标准输出且无需附带其他状态时，会直接把原始输出交给模型；需要报告错误、截断或存活进程等信息时，只附带必要字段，不重复返回原始命令和内部进程快照。`read_call`／`wait_call` 会重新核验已记录的进程身份，只返回当前确认存活的直接子进程的 PID 与名称；无法确认时报告观察错误。

### 网络访问

提供 `http_request`，用于 HTTP/HTTPS 请求、接口调用、上传和下载。需要目标地址可访问，以及请求所需的认证信息；它不是浏览器自动化工具。

本工具可自行上传或下载文件，不依赖“文件读”“文件写”两个工具组，但文件访问仍遵循授权规则。MCP 连接和命令中的网络访问不由此开关控制。

### 修改配置

提供 `update_config`，让 Agent 按你的要求修改支持的应用设置，例如主题、字号和资料。目前只能修改应用设置中的受支持字段，不能通过它任意改写项目、模型或 MCP 配置文件。

不依赖“文件写”。“严格审批”模式下每次调用需要确认；“智能审批”由模型判断是否需要确认；“完全访问”直接执行。

### 用户交互

提供 `request_user_input`，让 Agent 弹出问题，供你选择选项或输入答案。适用于缺少信息、需要澄清或选择方案的情况；你可以取消，普通问题也可超时返回。

此项不依赖后台工具。关闭后 Agent 仍可在聊天中提问，但不能使用这个交互弹窗；工具执行前的授权确认不受此开关影响。

### 等待

提供 `sleep`，让 Agent 等待一段时间后再继续，例如稍后检查网页或聊天回复。`seconds` 必填，只接受 1～300 秒的整数；`summary` 可填写等待原因。完成时返回实际等待秒数，之后仍需调用相应工具检查变化。

独立于“执行命令”和“后台工具”，在项目和子 Agent 的能力设置中单独启停。等待直接完成后返回，不在 10 秒后转后台；停止运行会取消等待。

聊天中的等待条目显示时钟图标和剩余秒数；倒计时到零后等待实际结果，完成后显示耗时。

### 文件读

直接读取和检查本地文件，不依赖“执行命令”。可验证的只读操作在所有授权模式下均免审，包括项目外文件。

| 工具 | 功能 |
| --- | --- |
| `read_file` | 读取单个 UTF-8 文本文件，可指定行范围；不读取二进制内容。 |
| `read_multiple_files` | 批量读取多个文本文件，分别返回结果。 |
| `view_image` | 查看一张本地图片，将画面提供给当前模型。 |
| `view_multiple_images` | 一次查看最多 10 张图片，逐张标明路径，单个失败不影响其他图片。 |
| `list_directory` | 列出目录的直接子项。 |
| `directory_tree` | 分页查看目录结构，最多展开 64 层，不跟随符号链接。 |
| `get_file_info` | 查看类型、字节大小、时间；自动补充图片尺寸与方向、音视频时长和轨道信息。 |

图片工具需要当前模型支持视觉且开启视觉能力配置；支持 PNG、JPEG、WebP，不依赖“执行命令”。原图直接发送，不缩放或重新编码；单图最多 8 MiB，批量图片数据合计最多 16 MiB。

`get_file_info` 只读取文件信息，不识别画面内容；无需安装额外的媒体分析程序。

文本搜索可使用“执行命令”中的 rg；“文件读”本身没有独立搜索工具。

### 文件写

直接创建、修改、移动或删除本地文件，不依赖“执行命令”。可单独选择所需工具；需要先检查原文时，还应启用合适的读取工具。写入按当前权限、安全目录和模型判断决定是否确认，详见[工具与授权](#工具与授权)。

| 工具 | 功能 |
| --- | --- |
| `apply_patch` | 使用 Codex 补丁格式按上下文修改文件；JSON 工具接口支持只预览不写入。 |
| `write_file` | 创建文本文件，或明确选择覆盖整个已有文件。 |
| `document_to_markdown` | 将 PDF、DOCX 或 PPTX 转为新的 Markdown 文件，并导出嵌入图片。见[附件与语音输入](#附件与语音输入)。 |
| `restore_file_edit` | 撤销有记录的整次 `apply_patch` 或 `write_file` 操作；恢复资料必须仍可用，遇到冲突不会直接覆盖。 |
| `get_file_edit_diff` | 查看 Agent 记录的文件改动，不等同于查看 Git 工作区差异；该工具本身只读。 |
| `create_directory` | 创建目录及所需的父目录。 |
| `move_file` | 移动或重命名文件、目录。 |
| `delete_file` | 删除文件或目录。 |

OpenAI Responses 使用 Codex 原生 freeform 补丁调用，供应商需支持 `custom` 工具；其他接口使用 JSON 参数封装，无需单独设置工具格式。补丁匹配允许上游定义的空白与标点差异；更新后的非空文件会带末尾换行。需要精确保留完整文本及末尾换行状态时可使用 `write_file`。

### 记忆

在 **设置 → 记忆** 选择记忆方式。默认是 **后台模型提取**。选择 **前台主动记忆** 时，支持工具调用的对话模型可使用 `update_memory` 写入全局或当前项目的偏好。调用和结果显示在聊天中。写入成功后，该对话截至本次用户消息的记录均已处理。切回后台时，从该位置继续；未成功写入的对话沿用原进度。

在后台模式下，应用从已保存的工作区对话中提取可复用的偏好，分别整理全局和项目记忆。开启项目“记忆”能力后，模型请求固定带入已完成的两份偏好；一次任务要求、代码版本事实和临时进度不作为永久偏好。新建或切换到任一对话后，首次成功发言时，后台检查所有其他已启用记忆的工作区对话中的未处理内容。仅切换浏览、在当前对话连续发言或重启应用不会触发整理。

在“设置 → 记忆”右上角可选择后台记忆模型。两种记忆方式下都能更改此设置，后台提取时使用所选模型。选定后按钮显示模型名称，可再次点击更换或清除选择。未选择或模型不可用时暂停整理，已有偏好仍可读取。记忆可能延迟生效；可在对话中提出纠正或忘记某项偏好。

从聊天窗口的 **工作区菜单 → 记忆活动** 可打开面板，入口位于插件下方。面板右上角的“标题栏按钮”默认勾选。标题栏右侧的记忆图标在实际运行时显示动画。点击查看来源、阶段、使用模型、候选证据、输入输出和整理后的记忆正文；面板可放在侧栏或独立窗口，关闭面板不会停止整理。本轮调用明细只在内存中保留到下一轮开始或退出应用。面板按模型上报的数据统计输入和输出 token，并显示已上报的调用次数。在 **设置 → 记忆** 下方可以查看和编辑全局 Markdown 正文。若后台在编辑期间发布了新内容，页面会保留草稿并显示最新正文，供核对后保存。在聊天窗口打开 **工作区菜单 → 项目记忆**（位于“文件改动”下方），即可查看和编辑当前项目的 Markdown。面板标题显示项目名称，移到独立窗口或移回侧栏时会保留草稿。有未保存的修改时，请先保存或取消编辑，再关闭面板。原记忆工具已移除，旧表原样保留但不读取或迁移；首次运行不创建旧表。

### 自定义工具

将你配置的程序或脚本作为工具提供给模型。需要准备对应的程序、依赖和账号；不依赖“执行命令”，交互式工具还需“后台工具”。配置和启用方法见[自定义工具管理](#自定义工具管理)。

### MCP

MCP 按服务提供复选框。勾选后使用该服务全部可用工具，包括后续新增工具；取消后关闭该服务全部工具。全局停用或没有已保存工具目录的服务不会向模型提供工具；已有目录的服务可在调用时启动。

需要在“设置 > MCP”中启用对应服务，并至少启动一次以保存工具目录。项目勾选只选择可用工具，不启动连接，也不能绕过全局停用。工具的作用、参数、依赖软件和账号由服务决定；它们不依赖同名的内置文件或网络工具开关。停用或不可用的已选工具仍可取消。

### 子 Agent

将独立任务交给其他 Agent，适合并行调查和分工。以下工具相互依赖，作为一组启停，不能逐个选择。

| 工具 | 功能 |
| --- | --- |
| `start_subagent` | 启动一个允许使用的子 Agent。 |
| `read_subagent` | 查看子任务的状态和过程。 |
| `wait_subagent` | 等待子任务进展、结束或需要确认。 |
| `cancel_subagent` | 取消指定子任务。 |

在“设置 > 子 Agent”中配置并启用子 Agent。项目和子 Agent 的能力设置以复选框选择允许启动的定义；未选中任何可用定义时无法启动。全局关闭或配置不完整的定义不可启动。此能力不依赖“后台工具”。

子 Agent 使用各自的能力配置，可继续调用其他子 Agent，但候选范围不能超出最初项目允许的范围。“限制子 Agent 能力”另行限制所有层级子 Agent 的上下文、工具和技能：勾选后只允许双方都启用的能力；未勾选时按子 Agent 自身配置执行。子 Agent 只收到委派任务，不自动获得整个主对话。

自定义子 Agent 在“标识”标题右侧可选择模型和参数预设。默认“使用父 Agent 的模型”，沿父级使用最近指定的模型及预设；选择独立模型后，后续创建的子任务使用该选择，清除选择即可恢复继承。修改子 Agent 定义不改变已有子任务的模型绑定；指定模型或预设失效时会报错，不自动换用其他模型。

子 Agent 使用目录包：

```text
subagents/<目录>/
  AGENT.json
  PROMPT.md
  skills/<技能>/SKILL.md
  tools/<工具>/TOOL.json
```

新建自定义 Agent 默认停用，所有能力初始关闭，按需逐项开启。

`AGENT.json` 保存 `version: 0`、稳定 `id`、`name`、`description`、`capabilities` 及可选模型选择；`PROMPT.md` 保存系统提示词。可先在设置中创建 Agent，再通过“在文件夹中显示”加入标准 Skills、工具及配套文件；也可用右上方的“导入子 Agent”多选文件夹并复制整包。导入不覆盖同 ID 或同名包；整批校验通过后再导入，有冲突或无效包时整批停止。导入会复制包内脚本、技能、工具和链接指向的内容，原件移走后副本仍可编辑。右上方的“添加目录”可引用外部 Agent 目录。左侧按“全部、内置、用户、外部目录”展示包和文件树，右侧显示 Agent 配置或文件预览。自定义提示词统一在文件树的 `PROMPT.md` 中预览和编辑，Agent 配置页不再重复展示；外部修改后点击刷新。

“添加外部目录”选择包含多个 Agent 包的父目录，直接引用原文件，不复制。目录可改显示名称、排序或移除；移除只解除引用，删除 Agent 则删除对应包。新增和导入的包保存在用户目录。Agent 可在同一来源内排序。外部目录不可用、包无效或 ID／名称冲突时会显示原因，其他有效包仍可使用；不可用包的开关保留。备份只保存外部目录引用，不包含外部文件，请单独备份这些目录。

左侧按钮区的上移、下移和删除作用于当前选中的外部目录或 Agent。内置 Agent、固定分组和包内文件不支持这些操作。

仅 `general-purpose` 内置于程序包 `data/subagents/`，承接综合执行任务。定义和所有包内文件由应用维护，只可查看，不可编辑、删除或改名；模型固定使用父 Agent 的模型，全部能力开启，实际可用范围仍受全局开关和项目对子 Agent 的限制约束。设置中仅保留整个 Agent 的启用开关，不提供“恢复默认”。自定义 Agent 包仍可直接编辑。

程序包的 `data/examples/subagents/` 提供 `web-researcher`（外部信息研究与来源核实）和 `project-analyst`（项目只读分析）示例，默认不加载。“导入子 Agent”默认打开此目录，可多选示例包并复制到用户目录，可以编辑、关闭或删除。示例直接读取程序包，不释放到用户数据目录；导入后的副本独立保存。包内示例不能通过“添加目录”作为外部来源引用；已有此类引用保留配置并显示不可用，不开放包内文件编辑。

自定义包内 Skills 和工具默认开启，可在该 Agent 的资源区逐项关闭，仅对该 Agent 生效，不出现在全局 Skills、工具列表或主 Agent 的资源中。关闭能力分组仍会停用该组资源；开启项目的“限制子 Agent 能力”后，还需在项目的对应来源中允许使用。项目中的“仅子 Agent”来源只控制子 Agent 的使用范围。同名资源在允许范围内优先使用包内版本；技能仍需要文件读取能力。运行中的工具占用目录时，定义修改、包删除及文件编辑会报错，待工具结束后重试。

包内资源开关属于能力配置，分别保存在 `capabilities.skills.package` 和 `capabilities.custom_tools.package`，按包内名称／ID 记录 `true` 或 `false`，未指定时默认开启。自定义包将这些选择写入 `AGENT.json`，复制或导入包时一同保留；内置包不提供资源开关。

子 Agent 管理配置现在使用 `config/subagents.json` v1，保存顺序、外部目录引用和整个 Agent 的启用开关，不保存内置覆盖配置。本次不迁移或兼容原 v0 数组配置；旧文件保留并报错，含该格式的备份也不能直接恢复。请退出应用并另行保存旧文件，再移走 `config/subagents.json`，重启后重新创建或导入 Agent 包。不要仅修改旧文件的版本号。

### 技能

向 Agent 提供可用技能的名称、用途和说明文件位置，或让你通过 `/name` 快捷调用。技能是操作说明，没有独立的调用工具，也不会自动赋予文件、命令或网络能力。

“技能”按条目勾选，只有顶层分组可折叠。插件技能随所属插件整体选择，独立于普通技能列表。

普通技能的“快捷方式”“模型可用”在全局技能页设置，插件技能在插件设置页配置，均作为对应技能的用途上限。项目和子 Agent 只选择整项启停，不能重新启用全局关闭的用途。子 Agent 只使用模型用途，手动引用的项目技能在项目中勾选后同时提供快捷方式和模型用途。

主动调用会直接发送技能文件原文和来源路径，调用后的文字作为独立的用户需求；可展开技能记录查看实际发送内容。模型自主读取技能说明或附带资料需要 `read_file`、`read_multiple_files` 或可读取文件的“执行命令”；技能中的脚本还依赖命令程序、运行环境、所需工具和账号。选择技能不代表这些依赖已经满足。在“设置 > 技能”管理全局来源和可用范围；项目技能目录在项目设置的“能力 > 技能”标题旁添加。安装、同名选择和编写方法见[技能手册](./AGENT_SKILLS.zh-CN.md)，安装要求见技能自己的 `SETUP.md`（如有）。

## 模型

支持 OpenAI 兼容和 Anthropic 兼容服务。在“设置 > 模型”中管理模型，在消息输入框底部切换使用。

左上角“新建”可选择空白供应商配置或模板，同一按钮区的上移、下移和删除作用于当前供应商；右侧模型列表有各自的操作按钮。“获取可用模型”保留在添加、编辑模型的窗口中，只更新候选模型列表，不修改已配置模型的能力和参数。

供应商菜单将 OpenAI Responses、OpenAI Chat Completions 和 Anthropic Messages 列为独立模板项，按已确认的接口提供；提供 Responses 的供应商将其放在首项。每个模板分别填写协议、Base URL 和模型列表地址。已有供应商切换协议时须同时核对 Base URL；模板更新不会覆盖已保存的配置。接口可用性和工具支持范围仍取决于供应商、模型及本地服务版本。

GLM 的 Responses 模板按[智谱官方说明](https://docs.bigmodel.cn/cn/guide/develop/responses/introduction)使用 `https://open.bigmodel.cn/api/v1`，Chat Completions 使用 `https://open.bigmodel.cn/api/paas/v4`；模型列表均从 `/api/paas/v4/models` 获取。

腾讯云模板位于 China → Tencent，分为 [TokenHub 按量](https://cloud.tencent.com/document/product/1823/130079)、[Token Plan](https://cloud.tencent.com/document/product/1823/130060) 和 [Coding Plan](https://cloud.tencent.com/document/product/1823/130092)。前两类按广州、新加坡地域分别提供协议模板；Token Plan 的广州入口同时适用于个人版和企业版，个人版通用与 Hy 套餐共用地址和密钥。请使用所购套餐、地域对应的密钥和模型 ID；企业版轻享仅支持 `auto`，个人版 Auto 为 `tc-code-latest`。Token Plan 模板使用同地域的 `/v1/models` 获取平台模型列表，调用仍走套餐地址；列表仅显示在线模型，不按已购买套餐筛选。已有配置可在模型列表地址设置中点击“恢复模板列表设置”，再重新获取列表。Coding Plan 提供 Chat Completions 和 Anthropic Messages 模板，使用独立的地址与密钥。未能获取模型列表时，可按腾讯云控制台填写模型 ID。

当前 Responses 协议下的 `apply_patch` 使用 custom/freeform 格式。[MiMo 要求这类工具使用 Responses Lite](https://mimo.mi.com/docs/tokenplan/integration/codex-configuration)，Anas 尚未适配 Lite；选择 MiMo Responses 模板不会消除这一限制，需要补丁工具时可选 Chat Completions 或 Anthropic Messages 模板。

供应商名称前的图标可点击或拖入 SVG、PNG、JPEG、静态 WebP 或 BMP 更换，悬停后可恢复默认。SVG 不超过 1 MB，保留原始矢量；位图自动居中裁成正方形，并缩小到最大 128 × 128 像素，统一保存为 PNG，小图不放大，保留透明背景。不支持 GIF 和动态 WebP。模板自带品牌图标；图片以 Base64 保存在供应商配置中，随配置备份。图标为空时直接显示通用图标。只有点击恢复默认时才按当前 API URL 查找模板，并保存匹配的品牌图标；找不到则清空。

API Key 可直接填写密钥，也可填写 `${VARIABLE_NAME}` 引用。下拉按 `.env` 和系统环境变量分组，推荐名称包含 `KEY`、`TOKEN` 或 `SECRET` 的变量（忽略大小写），只显示名称和空值状态，不提供搜索。手动引用不受推荐关键词限制；支持空格、中文、连字符和数字开头的名称，引用中的名称原样保留，例如 `${ TEST_API_KEY}` 与 `${TEST_API_KEY}` 不同。带首尾空格的下拉名称加引号显示，引号不属于变量名。引用格式不支持空名称、等号、大括号、换行或空字符；`.env` 文件仍按原规则去除赋值名称两端的空白。格式正确即可保存，变量不存在或为空时，在模型请求、获取模型列表或用量查询时明确报错。引用保持可见，直接填写的密钥失焦后遮罩。

同名变量优先使用应用数据目录 `.env` 中的非空值，否则使用系统值。在设置页保存 `.env` 后立即重新加载；外部编辑文件没有实时监听，重新展开变量下拉或重启应用会重新读取。系统变量来自 Anas 当前进程继承的环境，操作系统中修改后需重新启动 Anas；开发模式下也需重新打开启动终端。变更不影响已发出的请求。配置只保存引用，留空不自动选择变量；项目的 `.env` 能力开关不影响模型连接。

设置页和选择菜单的模型列表使用相同的双行展示：上方为模型名称，下方依次为上下文上限、最大输出、压缩阈值，以及能力和推理图标。未设置最大输出或关闭压缩时，对应位置显示“—”。

模型编辑窗口中的名称、能力、上下文限制、额外参数和推理选项先保留为草稿，点击“保存”后统一生效；点击“取消”或关闭窗口会放弃本次修改。

已配置图片限制的视觉模型，其眼睛图标中心显示为主题色。悬停眼睛、模型选项或当前模型选择按钮，可查看已配置的图片限制及大小计量口径；未配置时明确显示“图片输入限制：未配置”。

“视觉”旁的小设置按钮打开“图片输入限制”，可设置最小短边、最大长边、最大总像素、最大长短边比、单图字节数和单次请求图片数量；留空不增加限制。字节输入使用逗号千位分隔，K／M 按 1000 进制简写，可选择原始文件或 Base64 编码正文大小。添加图片附件时检查尺寸、比例和大小，不合规时拒绝添加并说明原因；提交前按当前模型复检，数量包括仍会发送的历史附件和待处理工具图片，失败时保留草稿。工具返回后合计数量超限时整批图片不发送，其他工具单图规则只省略不合规图片，并向模型说明原因。原始附件和工具结果保留，活动详情可查看省略说明。默认附件仅本轮携带，整个对话附件在有效上下文中继续计数，已消费的工具图片不再发送。远端 URL／file ID 图片不处理，也不纳入本地数量统计。二级弹窗确认后仍需在模型编辑窗口点击“保存”。

按模型实际支持情况设置“视觉”和“工具调用”。关闭“工具调用”后，模型不能调用内置工具、MCP 工具或子 Agent；资料、运行环境、项目信息、技能目录和自动记忆召回仍按能力设置提供，已保存的选择不变。

### 用量信息

在“设置 → 模型”选择供应商，API Key 标签行右侧的“显示用量信息”控制侧栏仪表。支持的 API 地址默认开启；不支持或无效地址取消勾选并禁用。切回支持类型时默认开启；同一支持类型内修改地址、重新打开设置或重启应用，会保留手动关闭状态。同一供应商下的模型共用这项设置。

腾讯和百炼在复选框后提供设置按钮，关闭显示时仍可编辑。腾讯填写 SecretId／SecretKey，百炼填写 AccessKey ID／Secret；取消不保存。密码默认遮蔽，仅输入框获得焦点时可见，失焦后恢复遮蔽。凭据随供应商保存到 `config/models.json` 并进入普通备份；遮蔽不是加密，不使用应用 `.env` 存放查询凭据。切换地址不删除已保存的厂商凭据。

仪表在聊天侧栏底部跟随当前模型，支持紧凑／展开、悬停及键盘聚焦详情、立即刷新。显示偏好按供应商保存，默认紧凑。自动查询缓存五分钟，切换显示或语言只重新呈现缓存。关闭显示停止查询；地址或凭据变更清除旧上下文读数。不支持的地址不显示仪表。一般查询失败保留同一上下文的成功读数，百炼失败清空读数。

支持范围：

- MiniMax Token Plan：5 小时与周额度，周额度包含接口返回的加成；显示剩余比例，不把重置时间当套餐到期日。
- GLM／Z.ai：Coding Plan 额度；国内 GLM 普通 API 显示人民币可用余额及实际返回的余额明细。余额不包含资源包或套餐额度，国际普通 API 不支持。
- DeepSeek、Moonshot／Kimi：余额与构成；Moonshot 中国站为人民币，国际站为美元，不跨币种求和。
- MiMo：普通 API 显示扣除冻结金额后的可用余额；中国、新加坡、欧洲个人 Token Plan 显示 Credits、周期和自动续费信息。
- OpenRouter：当前 Key 额度及消费，“未设上限”不表示账户有余额。
- 腾讯：查询凭据对应云账户的余额、广州／新加坡普通 TokenHub 本月用量；广州个人 General／Hy 套餐分别显示。不是当前模型 Key 的专属统计，企业套餐不查询；新加坡套餐和 Coding Plan 仅显示云账户余额。
- 百炼中国站：直接通过 RAM AccessKey 查询，无需安装 `bl` 或浏览器登录。套餐 Key 核对脱敏首尾后显示实际额度窗口与订阅信息；普通 Key 完整匹配后查询当前模型免费额度及此 Key 近七天在线调用。接口未返回 Token 明细时明确提示，不填零、不以工作空间统计替代。国际站和团队版专用地址不支持。

腾讯查询：为查询凭据对应的腾讯云用户添加 `ReadOnlyAccess` 权限，再在“设置 → 模型 → 用量查询设置”填写 SecretId 和 SecretKey。

腾讯和百炼用量查询设置均有“显示余额”。腾讯默认开启，关闭后停止独立余额请求，支持的用量和套餐查询保留；仅支持余额查询的地址会隐藏仪表。余额开启时排在用量前面。

百炼“显示余额”默认关闭。开启后使用同一组 RAM 凭据独立查询阿里云账户现金余额，需要 `AliyunBSSReadOnlyAccess`；详情提供可用额度及信用额度。用量和余额分别显示结果，一项失败不隐藏另一项的成功结果。

百炼 RAM 用户须完成[两层授权](#百炼-ram-授权与查询排障)。凭据缺失或授权失败时，仪表的“配置”返回当前供应商设置。

用量信息只使用模型设置，不接续旧用量仪表插件的开关、凭据或显示偏好。已有模型用量设置继续有效；缺失时按支持地址默认开启、紧凑显示和空查询凭据处理，额外凭据需在模型设置中填写。用量信息不再出现在插件列表，不需要启动插件后台。模型配置与数据库版本不变。

### 百炼 RAM 授权与查询排障

1. 在 [RAM 控制台](https://ram.console.aliyun.com/)创建用户和 AccessKey，授予 `AliyunTokenPlanReadOnlyAccess`、`AliyunBSSReadOnlyAccess`、`AliyunModelStudioFullAccess`。
2. 在[百炼 → 账号管理](https://bailian.console.aliyun.com/settings/workspace)添加刚才的 RAM 用户，再进入“权限管理 → 添加权限 → 选择业务空间”，添加“智能体-操作”。
3. 在 Anas 的“设置 → 模型 → 用量查询设置”填写 AccessKey ID 和 Secret，保存后刷新用量。

## 工具与授权

项目能力设置选择可用工具，模型的“工具调用”决定能否调用。各项用途和依赖见[项目与能力](#项目与能力)。

项目设置的文件夹下方，左侧选择默认权限模式，右侧选择模型及推理选项。新对话继承项目的权限模式，也可在输入框旁单独切换。已有对话保留各自的模式。未配置时使用“智能审批”。

输入框下方的权限模式按钮在空间充足时显示模式全称，空间不足时保留盾牌和下拉箭头。悬停或用键盘聚焦可查看当前模式全称，打开菜单可查看三种模式的说明；点击右上角“详细说明”，在侧栏打开用户手册并定位到“工具与授权”。

- **严格审批**：可验证的只读操作、项目、应用临时目录和系统临时目录内写入自动放行；其他操作需要确认。
- **智能审批**：默认模式。在严格审批的免审范围之外，桌面、下载、文稿和图片目录内写入也免审；其余操作由模型判断。代码确认安全的操作始终免审，模型未给出判断时请求确认。Freeform 补丁只按实际目标检查，安全目录外写入需要确认。
- **完全访问**：跳过执行前权限审核，保留校验、取消和恢复确认。可在输入框旁切换权限；排队调用执行前会按当前权限复查，切换不打断已经开始的操作。

只有智能审批下，相关 JSON 工具才提供必填的 `needs_approval`，要求模型每次显式填写；执行端漏传仍按 `true` 兜底。代码确认免审后，其余操作才使用模型填写的值。严格审批、完全访问及 Freeform 补丁不提供该参数。设置的工具详情可切换权限和补丁格式，查看对应定义。切换权限不改写历史调用参数，排队调用执行前按当前权限复查。

外部操作结果不确定时，仍需确认是否重试。等待确认的会话不能发送消息、编辑历史、重新生成或压缩，其他会话不受影响。

子 Agent 可在后台处理任务。点击其状态条可查看任务内容、工具调用和结果；主任务结束时，未完成或等待批准的子 Agent 会被取消。

## 运行环境与环境变量

“设置 > 环境”的“内置 rg”默认开启，向启用“运行环境”的项目和子 Agent 提供 rg 使用说明。

Python 自定义工具使用系统 Python 3，或在命令中显式指定的解释器。额外依赖安装到对应环境。原工具命令若显式使用 `{{bundled_python}}`，请将命令改为 `.py` 入口或自己的解释器绝对路径。

旧数据目录中的 `runtimes/` 原样保留，不再读取、不迁移、不自动清理；仍不进入备份，恢复备份和未知文件清理也不会删除它。“检测系统环境”更新系统命令信息，检测结果插入自定义环境信息中上次的光标位置；有选中文字时替换选中部分。

“自定义环境信息”默认开启。启动时若已勾选且内容为空，会在后台检测并填入，不阻塞启动；已有内容不覆盖，检测期间取消勾选则不填入结果。

在“设置 > 环境”中编辑应用 `.env`，为命令、自定义工具和技能脚本准备变量。是否传入这些变量由相应 Agent 的 `.env` 能力决定。

## 自定义工具管理

内置技能 `tool-manager` 可指导模型创建、修改和排查自定义工具，包含格式参考和 Python 示例模板。启用该技能及所需的文件操作能力后，可直接要求模型“为当前项目创建一个自定义工具”。测试脚本还需命令执行能力和对应运行环境；生成后可在能力列表核对工具是否选中。

“设置 > 工具”左侧上方是“内置工具”和“MCP”，右侧分别按能力和服务器分组。横线下方是自定义工具目录树：全部、系统、用户和添加的目录。点击分组名称在右侧查看工具列表，前方的方框箭头负责展开或收起；点击列表中的工具进入详情。点击详情标题可定位目录。也可展开工具包查看文件和预览文本；用户和添加目录中的工具可新增、双击编辑、删除及排序，删除会将整个工具包目录移到废纸篓。

右上方的“添加目录”直接引用外部工具目录，支持修改显示名称、排序和移除；名称在回车或失焦时保存，移除不会删除文件。左侧按钮区提供刷新，以及针对当前所选目录或工具的上移、下移和删除；工具只能在同一来源内排序。固定分组和包内文件不支持删除和排序。

每个工具目录包含显式声明 `"version": 0` 的 `TOOL.json` 和脚本或资源。用户工具保存在应用数据目录的 `tools/`；项目工具通过“能力 > 自定义工具”标题旁的加号手动引用总目录，仅供对应项目使用。编辑器配置名称、描述、JSON 参数规则和执行命令，不生成业务脚本或安装依赖。

页面右上方固定显示“新建工具”“导入工具”和“添加目录”图文按钮。默认保存到用户目录；选中外部目录或其中的工具、文件时，保存到该目录，按钮提示会显示目标位置。导入可多选目录，默认打开内置示例目录，提供文本读取、百度 AI 搜索、文件 SHA-256 和 JSON 格式化示例，均使用 Python 3 标准库。百度搜索另需联网和 `BAIDU_SEARCH_API_KEY`，配置见包内 README。导入会将工具包及链接指向的实际内容复制到所选来源目录。副本可独立修改，重名时保留已有工具。

详情页的“编辑信息”和“编辑参数”打开同一窗口，分别进入“基本信息”和“参数”页，切换时保留草稿。参数页支持“参数 / 源码”切换，可增删改参数，设置类型、必填、描述、枚举和范围等约束，并展开对象、数组编辑子参数。单个参数在窗口内编辑，应用后返回列表；点击工具“保存”后统一生效，放弃未保存修改需确认。脚本需自行同步修改。高级引用和组合定义使用源码编辑，其他未编辑的属性保持不变。默认值仅作说明，不会在调用时自动补入。

执行命令中的包内脚本路径可点击定位到左侧文件列表。文件不存在时，可确认创建空文件及缺失目录；已有文件不会被覆盖。

程序包内的示例和工具模板须先导入为用户副本。项目及外加目录不能引用程序包资源目录、其父目录或目录别名；已有引用保留配置并显示不可用。文件编辑按实际目标检查，指向程序包内文件的链接只读。

在工具详情中管理全局启用状态，在项目和子 Agent 的能力列表按工具勾选。条目按来源分组，一行可显示多个工具并随宽度换行。子 Agent 使用独立选择，可勾选“使用当前项目工具”，并遵循项目限制。同名时优先使用项目工具目录顺序中的有效启用项，其次为用户工具、按顺序排列的外加目录。

命令在工具目录运行，相对路径从这里解析，例如 `scripts/run.py {{args}}`。`.py` 入口使用系统 Python 3。独立参数 `{{args}}` 接收完整 JSON；`{{tool_dir}}` 表示工具目录绝对路径。命令只启动一个程序及固定参数，不支持管道或重定向。程序的标准输出作为结果返回模型；大段输入宜通过文件传递。

“交互式终端（PTY）”用于需要后续输入的程序，依赖“后台工具”，无需开启“执行命令”。普通文本结果不需要开启它。超时留空表示不限时，填写正整数秒可限制执行；等待输入也计入超时。取消或超时会终止进程树，但不会撤销已经发生的修改。

## MCP 设置

在“设置 > MCP”中添加和编辑服务，支持 stdio、HTTP 和 SSE。服务及其工具需启用，模型需开启工具调用，项目需允许使用对应服务。

应用启动时不会连接 MCP，即使服务已启用。模型读取已保存的工具目录；尚无目录的服务需先在设置页点击“启动”获取目录。没有工具列表或列表为空时，不能从关闭切换为启用；启动不受此限制，已有启用状态仍可关闭。每次启动成功后自动更新并保存工具定义，包括成功返回的空列表。连接或获取目录失败保留旧目录。

设置页提供“启动／停止”和工具复选框，可逐项选择或全选／全不选。点击复选框或工具名切换可用性，悬停查看简介。工具详情统一在“设置 → 工具 → MCP”查看和复制，不会启动服务。无论是否启用，均可手动启动以获取或刷新目录；“启用”只控制模型可用性，切换不会启动或停止连接。目录和选择随修改保存，不依赖点击停止；停止只关闭当前连接，保留目录和选择，之后调用仍可按需启动。整体停用服务或单独停用工具会撤下相应模型工具。

调用未运行的服务时，对话工具活动显示“正在启动 MCP xxx”；启动成功后继续原调用，失败通过原调用返回启动错误。若刷新后该工具已不存在，原调用返回“此工具已不存在”；后续模型请求使用新目录，不再提供已移除的工具。并发调用共享一次启动，启动成功后连接保持运行，直到停止或退出。

右上角“新建 MCP 服务”创建配置；左上角按钮区可上移、下移或删除当前选中的服务。刷新图标检查运行中的服务，并重连失败或不通的服务；不会启动从未运行或已手动停止的服务。

stdio 服务的“工作目录”留空时使用当前用户主目录；需要在其他目录运行时，填写该目录的绝对路径。

停用的服务仍可编辑；修改连接配置会停止对应连接并使旧目录失效，需重新启动获取。改名称、排序和工具选择不会启动或重启服务。“设置 > 工具”的工具目录按服务展示工具，项目中可按服务进一步限定工具可用范围。

## 附件与语音输入

附件说明只向模型提供已知的原始完整路径，不提供归档路径。附件卡片显示文件名，悬停查看原始路径；发送后读取归档副本。历史图片省略图像数据时仍保留文件名和原始路径，模型可按需重新查看原文件；应用预览继续使用发送时的归档副本。旧附件没有原始路径时，只提供文件名。

会话数据库 v3 会在启动或恢复备份时自动升级到 v4，旧附件的原始路径留空。启动升级前会将原库及恢复日志保存在系统文档目录的 `Anas/backups/before-upgrade/`；升级失败可重试。恢复备份时只升级解压副本，原备份文件不变。恢复不逐条校验数据库记录，也不要求附件文件存在或大小一致；附件可用性在实际加载时判断。

附件发送后会保存本地副本，原文件移动或删除不影响查看。默认只供当前一轮使用，点亮固定按钮后可在同一会话的后续轮次继续使用。发送前，将鼠标移到附件上可显示删除、后续携带和“转为路径”按钮。转为路径会移除待发送附件，在输入框末尾追加已知的原始绝对路径，保留已有文字；多个路径各占一行。编辑历史消息时也使用原始路径；只有缺少原始路径的临时附件才先保留到所属会话目录，再使用保留副本的路径，保留文件随会话删除。

纯文本、Markdown、HTML 及 SVG 源码按文本附件发送。图片需要模型开启视觉。选择或拖入其他文件和文件夹时，其原始路径会追加到输入框，每项各占一行。

原生文件工具 `document_to_markdown` 可将 PDF、DOCX、PPTX 离线转换为 UTF-8 Markdown。在项目或子 Agent 的“文件写”能力中可选择此工具。

- `input_path` 必填，填写源文档的绝对路径。
- `output_path` 必填，填写新 Markdown 文件的绝对路径。工具会创建缺少的父目录，目标文件已存在时会报错。
- `summary` 可选，模型填写时显示在聊天的工具名旁，省略时显示源文档路径。

工具成功后返回 `[Converted document · Markdown]` 标记、源文件和实际保存的文件路径、Markdown 行数和字节数。启用“文件读”后，模型可用 `read_file` 按行读取正文。单行超过模型的字节预算时，启用“执行命令”后可用脚本分段读取。

有嵌入图片时，工具按输出文件名创建同级图片目录。例如，`报告.md` 引用 `报告_images/` 中的图片。Word 和 PPT 图片保留在正文对应位置，PDF 图片跟在对应页的正文后。移动或分享 Markdown 时，请同时带上图片目录。目标图片目录已存在时，工具会提示更换输出路径。

PowerPoint 转换会跳过手写墨迹及其预览图。同组的文字、表格和普通图片会保留。文本框、表格和演讲者备注中的 Office 公式优先写为 LaTeX。遇到不支持的公式结构或数学字体（例如 ℝ 的双线体）时，保留整条公式的 Office Math XML。嵌入的 MathML 公式以 XML 代码块呈现。如果 MathML 无法解析，会保留可用的备用表示，例如预览图。如果只有整组预览图，会一并保留组内可读取的文字和表格。缺少可用表示时，在原位置标注。

嵌入的 SVG 可以用浏览器打开。普通 EMF、WMF 图片在 Windows 上可转为 PNG 并显示在正文中；其他平台或 Windows 无法渲染时，保留原图的文件链接。TIFF 图片也以文件链接保留。由多个形状拼成的关系图会提取各形状的文字，空间关系需对照原稿。

单个源文件上限 64 MiB，Office 文件解包后最多 256 MiB、32,000 项。扫描 PDF 可导出页内图片，提取可搜索文字需要原文件带文字层。旧版 .doc 和 .ppt 需先另存为新版格式。

点击麦克风按钮可调用 Windows 语音输入或 macOS 听写。开始、停止和识别语言由系统控制；macOS 需先在“系统设置 > 键盘 > 听写”中启用。确认系统听写已开始，输入结束后检查文字再发送。Anas 不录制或保存音频。

语音回复直接连接微软 Edge 在线语音服务，需要联网，待朗读文本会发送给微软。音色和语速可在设置中调整；音频仅在内存中暂存，停止播放或切换会话会取消未完成的合成并释放待播音频。

自动朗读随主模型正文分段播放。后续工具调用、等待审批或子 Agent 工作出现时，尚未开播的回复会取消朗读；已经开播的回复继续播放，包括分段之间等待合成的情况。新一轮主模型开始输出正文时，停止旧音频并切换到新回复；思考和纯工具调用不会打断已经开播的回复。最终消息不会重复播放已朗读或已取消的内容。

## 会话与上下文

在聊天的运行过程中，如果工具调用带有非空字符串 `summary`，工具名旁会优先显示模型填写的这段操作说明。这条规则适用于内置、Shell、自定义、插件和 MCP 工具。工具可以不声明这个参数。省略摘要时，界面会尝试显示描述、路径、网址、查询或命令。这些参数也没有时，只显示工具名。

在 **设置 → 对话 → 聊天显示** 统一调整聊天内容宽度、运行过程展示和轮次信息。运行过程可默认展开或收起；新回复出现或运行结束时自动收起，之后仍可手动展开。轮次信息开关控制每轮模型调用的编号和用时。

Agent 页面左侧为项目和会话，中间为对话；帮助、子 Agent 和“文件改动”在右侧工作区打开。拖动分隔线调宽，或放大右栏；窄窗口使用可调宽的抽屉。收起右栏或切换会话会保留标签和查看位置。关闭子 Agent 标签不会停止任务。

帮助、文件改动、子 Agent 和插件均可右键点击标签，选择「移到独立窗口」；通过独立窗口标题栏图标移回侧栏。切换位置保留页面状态和连接。“文件改动”全局只打开一份，跟随当前项目和会话，标题显示项目名称；切换项目不会收起侧栏，已独立显示时再次点击入口会聚焦原窗口。切换上下文后重新选择运行和文件。子 Agent 独立窗口仍绑定原项目和会话，移回时自动定位原会话。

拖动右侧标签可调整顺序，靠近标签栏边缘会自动滚动。明显拖离标签栏后松手可移到独立窗口，按 Esc 取消。切换会话、收起展开和移出再移回会保留顺序；仅支持侧边栏的插件不能拖出。

独立面板进入全屏后，操作按钮保留在可拖动的浮动工具栏中；插件也可提供带分组的工具栏菜单。跨显示器移动和程序自动适配窗口与用户主动调整大小分开处理，避免无意改变插件内容尺寸。

在“文件改动”中选择比较范围和文件，查看只读差异。顶部工具可切换行内／左右对比、折叠未修改区域。Git 比较支持工作区、暂存区、分支、标签和提交。历史原文不可用、二进制或超过 1 MB 的文件会提示无法显示差异。

“回合改动”显示当前会话有记录的文件修改，包含子 Agent 的改动，非 Git 目录也适用。默认比较该回合首次修改前与最后修改后的内容；“对比当前文件”改为比较当前磁盘内容，可能包含后续修改。消息下方的“本回合改动”可直接定位该回合。有记录时可点击，检查中或运行中暂无记录时置灰；回合及子任务结束且确认无记录时隐藏。修改后又撤销的记录仍可查看。

点击“审核所选范围”可让 Agent 审核差异；发出的消息会显示实际审核指令和差异内容。

会话自动保存，侧栏显示用户发送消息的轮数；较早的消息可按需加载。执行过程显示工具调用、等待批准、失败原因和耗时。页面自动跟随新输出；向上滚动或展开详情时暂停，滚回底部或点击“滚动到底部”可恢复。

长对话会自动压缩上下文，也可通过输入框旁的上下文指示器手动压缩。指示器分类显示估算用量，预留输出空间单独显示，不计入已用上下文。

上下文超限时，过长的工具结果可缩短为预览，并附上完整结果文件的路径；原始聊天记录保留。文件位于数据目录的 `db/projects/<projectId>/conversations/<主对话ID>/tool_results/`，随应用备份保存、随整个对话删除；清缓存不影响这些文件。

项目编辑窗口的“预览请求”可检查当前项目将提供给模型的上下文和工具。

## 插件

“安装插件”默认打开程序包的 `data/examples/plugins/`，其中提供记事本、可选后台、文本工具和写作助手四个独立 ZIP 示例，直接选择 ZIP 即可安装，无需解压。需要阅读或修改源码时可自行解压；安装后的用户副本独立保存，不随应用升级覆盖。

「设置 → 插件」的概览按提示词、技能、工具分组展示，悬停名称查看简介。技能和工具在此配置可用性，预览入口分别统一在「设置 → 技能」和「设置 → 工具 → 插件」。提示词仍可点击查看、切换预览／源码并复制。插件停用或后台未启动时也能查看，预览不会启动后台。

「设置 → 工具 → 插件」按插件展示工具目录，可查看和复制名称、描述及完整输入参数，详情同时显示操作类型和超时。停用的插件和工具仍可查看，名称以警示色显示，原因放在 tooltip 中；浏览目录不会启动插件后台。

“设置 → 插件”可逐项开关提示词和工具，每组提供全选／全不选。插件技能在同一页面分别设置“快捷方式”和“模型可用”，两项全关即停用，新技能两项默认开启。技能组标题的全选／全不选图标同时切换组内全部技能的两种用途，部分选中时点击全选。插件整体或依赖工具停用时，用途选择继续保存，重新启用后生效；名称的提示会说明停用原因。项目和子 Agent 按整个插件选择使用范围。技能页支持浏览插件技能、查看已选用途，并跳转到所属插件设置。

项目和子 Agent 选择的插件工具可在没有插件页面的情况下调用，文本、JSON 或图片结果沿用普通工具的对话显示。停用后不能调用；更新插件后按当前工具定义使用，不因版本变化要求重新建对话。取消或超时只通知后台停止当前调用，不会因此终止整个插件后台；发出取消不代表操作已经停止，仍以后台回执为准。

Anas 3.3.8 起仅运行插件 API 2 的插件，旧版插件须先更新。RDP 插件 0.1.9 需要 Anas 3.3.13 或更新版本，请先更新宿主，再安装插件。

在“设置 > 插件”中点击“安装插件”，默认筛选插件 ZIP 文件；选择已构建插件目录中的 `PLUGIN.json` 时，切换到插件清单筛选项。ZIP 无需手动解压，清单须位于压缩包根目录，或唯一的顶层文件夹中；选择 `PLUGIN.json` 会安装它所在的整个目录。也可将一个 ZIP、`PLUGIN.json` 或插件目录拖入插件页面；目录根部须包含 `PLUGIN.json`。拖拽安装沿用相同的校验和覆盖确认，安装或确认期间不接收重复拖入。对话顶部的“工作区菜单”按当前项目和插件分组：项目名下可打开文件改动；插件组列出有首页的已启用插件，按首页打开位置显示在右侧工作区或独立窗口。插件标题右侧的齿轮可直接打开插件设置，没有可启动插件时仍保留该入口。界面插件的概览中可开启“在标题栏显示启动图标”（默认关闭），将常用插件放在菜单旁；停用时隐藏图标但保留设置，覆盖安装也会保留。宽度不足时，仍可从菜单打开插件。无首页插件在设置中管理，工具、技能和提示词按能力设置生效，无需手动启动。纯界面插件没有后台进程；可选后台在首次调用时自动启动，也可在设置中手动启动或停止。

同 ID 插件已安装时，会显示新旧版本并询问是否覆盖。确认后关闭该插件的页面和后台，保留启用状态和标题栏图标设置并替换安装包。默认不勾选「删除插件数据」，原配置、凭据等数据会保留；勾选后清除该插件的数据，但仍保留这两项安装设置。取消不会影响现有插件；安装失败会尝试恢复旧包、安装设置和数据，无法恢复时会保留文件并报告位置。

用户插件代码直接安装到 `plugins/<id>/`，设置与数据统一存放在 `db/plugins/<id>/`，安装状态文件为 `anas-installation.json`。旧 `package/` 布局不自动迁移，已有用户插件会显示加载错误，重新覆盖安装即可；保持「删除插件数据」不勾选，首页位置、配置、凭据等数据会保留。内置插件不受影响。旧 `plugins/<id>/installation.json` 不再读取，新安装状态文件缺失时默认启用插件、不显示标题栏图标。恢复含旧路径的备份也按此规则处理。卸载时删除安装状态文件，即使保留业务数据，重新安装的启用状态和图标设置也恢复默认。

收起面板、切换会话或进入设置保留插件页面状态，关闭标签会销毁该页面。Windows／Linux 关闭主窗口会退出应用，同时关闭独立面板和插件后台；macOS 关闭主窗口只隐藏，使用“退出”结束应用。通过标签右键菜单「移到独立窗口」和独立窗口标题栏「移至侧边栏」切换位置；插件保存界面状态并在目标页面恢复，后台连接继续运行。交接失败会保留原页面。每个插件最多保留一份首页，再次启动会显示并聚焦它所在的侧栏或窗口。其他业务页面共享已保存的数据和后台，各自保留自己的页面内容。刷新窗口会释放其中的页面，后台资源仍由插件管理，重新打开时按插件能力恢复。在「设置 → 插件」选中插件，可设置首页打开位置，停用时也可修改；关闭已有首页后，下次创建时生效，固定位置的插件不能切换。停用或卸载会关闭页面和后台。卸载默认保留数据，重新安装同 ID 后可继续使用；勾选「删除插件数据」则同时删除该插件的配置、凭据及其他数据，已有备份不受影响。

插件替换或卸载中途退出时，下次启动会先恢复未完成的操作，并清理已完成操作的残留。恢复材料不会被清理缓存或临时文件删除；若日志损坏、目录冲突或恢复失败，启动恢复界面会提示保留位置，解决问题后可重试。

插件与其数据包含在应用备份中；备份会先停止后台，恢复不会自动重启。带后台的插件可使用当前用户的系统权限，应安装你选择信任的插件。插件出错会单独显示在插件设置中，不要求重置应用配置。

## 本地数据与备份

**从 4.0 之前版本升级到 4.x，旧对话和全部长期记忆（含项目记忆）不再可用；项目、输入历史、插件数据和头像可手动恢复。** 升级前备份整个数据目录。受影响的数据、路径对应关系、手动恢复和残留清理方法见 [4.x 升级数据说明](UPGRADE_TO_4.zh-CN.md)。

Anas 5.0 默认使用 `~/.anas/`，开发与打包版本一致，重命名程序不会改变目录。不会自动读取或迁移此前 `~/.anas-next/` 或旧 Anas 目录中的数据；使用其他独立目录时，请显式指定 `--data-dir <路径>`。

**从旧框架版本升级到 5.x 时使用全新的原生数据库。** 不复制旧框架版本的 `db/`，不迁移其对话、记忆和运行记录，也不恢复其整包备份。可以在退出应用并备份后复制受支持的配置、`.env`、用户 Skills、工具、子 Agent 和插件代码；外部引用仍须可访问，项目和数据库内容重新建立。当前格式为 catalog v2、会话 v3、独立记忆 v1，支持自身的备份与修复；已有当前格式数据无需再次重置。较早 5.x 的布局和会话版本变化及配置复制步骤见 [5.x 升级数据说明](UPGRADE_TO_5.zh-CN.md)。

也可启动时指定目录，例如 `Anas.exe "D:\Anas Data\Research"` 或 `--data-dir <路径>`。相对路径以启动目录为准，不能使用文件系统根目录。

备份保存为 zip 文件，默认位置为当前系统用户“文档”目录下的 `Anas/backups/`；已经选择过保存目录时继续使用该目录。备份包含用户工具和技能；项目源文件夹及外部引用的技能、工具文件需另行备份。不包含运行日志、临时文件、开发请求追踪、应用缓存、界面缓存和登录状态，以及旧布局残留。

导入备份前，当前数据自动备份到系统“文档”目录下的 `Anas/backups/before-restore/UTC时间戳Z-随机后缀/`。自动保全目录必须位于活动数据目录之外；保存失败时停止操作，不回退到临时目录。旧位置的备份原地保留。

“设置 > 通用”中的“数据清理”隐藏已确认没有可清理内容的项目。会话清理保留置顶、运行中和等待批准的会话。“未知文件”默认不选中，可展开查看白名单外的路径，目录以 `/` 结尾；清理包含旧布局残留和数据根目录中的备份文件。需要手动恢复的旧项目、输入历史、插件数据和头像应先移到新目录或另行备份，再清理对应旧文件。`cache/` 只由缓存清理处理，`db/projects/<projectId>/conversations/` 只由对话删除处理。

从对话菜单删除整个对话时，无须先修复已缺失、损坏或版本不匹配的会话数据库；删除会同时清理该对话的附件、文件修改恢复材料、长工具结果和临时草稿。如果系统拒绝删除文件，会保留删除进度，解除占用或权限问题后可重试。

| 数据目录内的路径 | 内容 |
| --- | --- |
| `config/` | 设置、供应商与模型、子 Agent 顺序与开关、MCP、Skill 来源与可用性、自定义工具来源与排序 |
| `db/catalog.sqlite` | 主会话目录与共享记忆 |
| `db/projects/<projectId>/conversations/<threadId>/conversation.sqlite` | 一个主会话及其子 Agent |
| `db/projects/<projectId>/project.json` | 项目定义与源码目录 |
| `db/input_history.json` | 全局输入历史及置顶输入 |
| `.env` | 应用环境变量 |
| `db/projects/<projectId>/conversations/<threadId>/` 下的 `attachments/`、`file_edits/`、`tool_results/` | 该主对话及其子 Agent 的附件、文件修改恢复材料和长工具结果；随对话删除 |
| `skills/`、`tools/` | 用户管理的包 |
| `subagents/` | 子 Agent 定义、提示词及私有 Skills、工具 |
| `plugins/`、`db/plugins/` | 已安装插件及独立数据；卸载默认保留数据，可勾选删除 |
| `lang/` | 用户语言包；内置英文、中文直接读取程序包 |
| `config/assets/` | 头像原图、裁剪参数及生成图标 |
| `log/`、`cache/`、`tmp/`、`electron/` | 日志、缓存、临时文件与 Electron 用户配置 |

内置技能、子 Agent、示例、帮助和内置语言直接读取程序包 `data/`，不释放到上述数据目录。旧 `_system`、示例、帮助和内置语言副本原样保留，不再作为内置来源加载。用户配置、资源选择和导入后的包继续独立保存；备份恢复无需携带内置副本。

本文所述包内 `data/`，在 Windows 位于 `<程序目录>/resources/data/`，在 macOS 位于 `<Anas.app>/Contents/Resources/data/`。开发时直接读取仓库 `data/`，生成后的示例使用 `out/examples/`。用户 `lang/` 可为空，仅用于添加自定义语言；旧 `en.json`、`zh-CN.json` 不覆盖当前内置翻译。

## 故障排查

“设置 > Dev”提供开发者工具、日志查看，以及“控制台方式启动”。后者会保留当前数据目录并重启应用，在系统终端显示启动和运行输出。

- **自动恢复**：工具调用格式错误、响应中断或达到输出长度上限时，程序会尝试恢复。与网络重试共用每个失败点最多 2 次自动恢复，默认等待 0.5 秒、1 秒；服务要求等待更久时遵从其等待时间，等待中可停止。已完成的工具不会重复执行；被截断的工具调用会重新生成，已生成的回答文字会保留并继续。界面显示恢复原因和次数，耗尽后保留错误及手动重试。附件无法读取或提取时，会告知模型内容缺失；不会依据本地图片解码结果拦截或转换图片。
- **模型调用失败**：检查服务地址、模型名、密钥和网络连接。错误下的“重试”会从失败的模型请求继续，不重新执行已完成的工具。仅在错误前紧接工具结果、没有后续用户输入时，才显示“重试（不返回工具结果）”；这批工具返回值会在数据库中替换为用户主动不返回结果的说明，对话记录和后续模型请求读取同一份更新后的内容。工具已产生的操作不会撤销；替换结果随备份、重启和后续对话保留。中间错误也可重试：确认后会移除该错误之后的对话内容，从该位置继续；已经执行的工具操作不会撤销。
- **技能失败**：检查技能说明、环境变量和所需程序。
- **MCP 工具未出现**：确认服务已启用、已启动过并保存工具目录、对应工具已勾选、模型已开启工具调用，并检查项目能力选择。
- **操作等待确认**：按提示允许或拒绝；结果不确定时，只在接受可能重复执行的情况下重试。

### 启动恢复

启动加载失败时，恢复页列出出错文件，可查看错误详情、打开日志目录，并选择：

- **修复**：用默认值修正错误配置项，保留有效设置。能力选择按当前配置格式逐项校验；无法识别的值恢复对应默认值，不转换旧格式的含义，也不因能力配置出错重置整个文件、项目或会话。没有条目默认值的无效选择列表恢复该列表的默认值；无法解析的配置文件仍可通过单文件重置恢复。项目定义损坏时按目录身份抢救有效设置，缺失字段补齐默认值。具体修改列在错误详情中。
- **重置**：配置重置只恢复所选配置。**重置会话数据库**清空会话、运行、共享记忆、附件、工具结果和文件修改恢复材料，保留项目定义和项目设置。**重置全部项目与会话**才同时删除全部项目定义。两种操作均先保全原始数据，保留项目源码、其他配置、Skills 和输入历史；确认框逐项列出实际文件和目录，目录明确包含全部内容。执行清单若有变化，必须刷新并重新确认。

操作前自动保存原始数据到系统“文档”目录下的 `Anas/recovery/UTC时间戳Z-随机后缀/`，保存失败则不修改。处理完成后重新启动。

应用自有持久化数据以显式格式版本 `0` 为当前原点。自动升级和手动修复分别处理：版本缺失、不匹配或自动升级失败，都可以在恢复页尝试“修复”。输入历史和头像资产出错也会在进入主界面前进入恢复页。程序先保全原始数据，再尽力修复配置、输入历史、头像、项目及关联数据库；有效设置、项目身份、会话和记忆尽量保留。项目修复从有效会话重建目录索引，无法恢复的内容在保全副本中原样保存，并从活动数据中隔离；补齐必要结构并验证可启动后才发布结果。报告会区分恢复结果和剩余问题，避免损坏数据持续阻断进入程序。

输入历史可逐条恢复有效记录，保留顺序和置顶状态；坏条目保留在原文副本中并报告部分修复。若非空历史完全无法识别，不会将其修复为空列表。项目修复会保全并隔离未完成的删除日志与暂存文件，不重放删除操作；有效的项目写入日志内容仍用于抢救最新设置。

头像修复从仍可读取的原图、裁剪图或显示图重建所需资产，修改前保全原文件；没有可恢复图像时报告问题，不自动换成默认头像。导入备份时还会在替换数据前检查头像参数，拒绝不支持的版本或损坏参数；尚无头像参数不影响正常初始化。

### 打开下载的 macOS 应用

从 [GitHub Releases](https://github.com/higale/anas-agent/releases) 下载适合你 Mac 架构的 DMG，打开后将 Anas 拖入“应用程序”，再启动安装后的副本。如果 macOS 因无法验证开发者而阻止启动，请按 [Apple 的说明](https://support.apple.com/102445)，在“系统设置 > 隐私与安全”中选择“仍要打开”，然后确认“打开”。

如果上述方法仍未解决下载隔离问题，且你信任此版本，请先将 DMG 的 `shasum -a 256` 输出与该 Release 的 `SHA256SUMS.txt` 对应条目比较，再仅移除已安装 Anas 应用的隔离属性：

```bash
xattr -r -d com.apple.quarantine "/Applications/Anas.app"
```

如果安装在其他位置，请修改路径。仅在权限不足且确认路径正确时，才在命令前添加 `sudo`。此操作只移除下载隔离标记，不修复损坏的应用，也不提供 Apple 公证。签名校验失败时请重新下载，不要用此方法绕过恶意软件警告。

发布构建已应用并验证 ad-hoc 签名。用户通常不应运行 `codesign --force --deep --sign -`：它会替换嵌套代码的签名，[Apple 将深度签名限定为应急修复用途](https://developer.apple.com/library/archive/technotes/tn2206/)。开发者可以通过 `npm run pack:mac:release` 重新构建。未来如果采用 [Developer ID 签名与 Apple 公证](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)，可以避免因开发者身份或缺少公证导致的拦截；当前版本使用 ad-hoc 签名。
