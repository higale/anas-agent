# Anas 用户手册

语言：[English](./USER_GUIDE.en.md) | [中文](./USER_GUIDE.zh-CN.md)

GitHub：[higale/anas-agent](https://github.com/higale/anas-agent) · 开源协议：[MIT](https://github.com/higale/anas-agent/blob/main/LICENSE)

Anas 是一个本地桌面 Agent。你可以为不同项目配置上下文、工具、技能和子 Agent。配置、会话和记忆保存在本地；完成任务所需的内容会发送给你配置的模型服务。

在左下角菜单选择“帮助”，即可在右侧工作区阅读手册。用“目录”跳转章节，点击文内链接打开相关手册；关闭、放大或切换标签不影响聊天。

## 快速开始

1. 在“设置 > 模型”中添加模型服务，填写地址、模型名和密钥。
2. 在消息输入框底部的工具栏中选择模型。
3. 输入消息并发送；需要时可添加附件或选择项目。

工具执行期间，工具调用标题整行显示连续流光，包含图标、工具名、说明、状态标记和操作入口，不影响点击或展开。等待用户确认或回答、调用结束后停止；系统启用“减少动态效果”时显示普通文字。

## 项目与能力

在项目编辑窗口开启“定制能力”，可设置项目提示词、上下文、工具、技能和子 Agent。关闭后使用所有已启用的能力，自定义选择保留。设置页只管理各来源的启用范围，不再提供默认能力页。“编码模式”独立控制开发工作方式，不会提高授权范围。

默认项目仅可修改图标、颜色、工具权限、模型及推理选项；名称、工作目录和其他项目设置使用默认值，使用所有已启用的能力。需要自定义目录、提示词或能力时，请新建普通项目。

- “文件读”“文件写”和“记忆”可展开逐项选择，也可通过分组开关全选或取消。已删除或不可用的已选项仍可取消。
- 下文列出的工具都需要模型支持并开启“工具调用”。上下文类能力不需要工具调用；技能的实际使用还取决于读取文件和执行任务所需的工具。
- 能力选择决定提供什么工具，授权模式决定执行具体操作时是否需要确认。关闭“文件读”“文件写”或“网络访问”只撤下对应工具；执行命令和 MCP 仍可能提供同类操作。
- 修改只影响之后启动的任务；已经运行或等待恢复的任务继续使用启动时的选择。

每个 MCP 服务、插件，以及子 Agent、技能和自定义工具分组统一提供“全部／定制／关闭”。全部包含当前及以后新增的可用条目；定制只包含明确选择，列表默认收起；关闭保留定制选择且隐藏列表。已定制项目新增 MCP 服务或插件时默认关闭。来源整体停用不锁定定制：已知条目仍可编辑，但不会生效；MCP 无法获取完整列表时，仍可取消已保存的工具。

技能的快捷方式／模型用途受全局设置限制：全局关闭后，未选中的用途不可选择且不显示提示；已保存的选择保留，以警告色提示冲突并允许取消。重新全局启用后才可再次选择。项目本地技能不受此限制。

- **全开**：启用内置能力，将当前 MCP 服务、插件及其他分组设为“全部”，并取消项目的“限制子 Agent 能力”。仍遵守各来源的全局启用范围。
- **全关**：关闭各项能力；保留 MCP、插件、自定义工具、技能和子 Agent 的定制选择。

在“设置 > 工具”左侧选择“内置工具”或“MCP”，右侧分别按能力或服务器分组；点击工具名查看参数和完整说明。横线下方通过目录树浏览自定义工具及包内文件。

### 编码模式

“编码模式”独立于“定制能力”。它加入先读代码、保护已有修改、验证结果等开发规范，并使用保留文件修改、测试证据和待办事项的压缩摘要。模型、工具和访问权限仍按各自设置生效。

应用自动读取适用的 AGENTS 规则全文，并直接加入系统上下文，无需模型先调用读取工具。同目录优先使用 `AGENTS.override.md`，不存在时使用 `AGENTS.md`；更深目录规则只适用于对应目录树。规则占用输入 token，每次运行保留已检查目录的快照。

初始加载主工作目录适用的规则，其他目录按结构化文件操作的目标路径发现。如果写入依赖尚未告知模型的新规则，会先返回“未执行”，让模型看到规则后重新决定。任意 Shell 命令、未声明文件目标的 MCP 或自定义工具不会自动检查全部受影响路径。

普通工作区项目的提示词区域提供“项目提示词”和“压缩提示词”两个标签。压缩提示词留空使用当前模式的内置默认；点击“载入默认”可在默认全文上修改。非空内容完整替换默认，清空恢复默认，修改随项目保存或取消。两项提示词均需开启“定制能力”才可编辑并生效；关闭后使用默认行为，已有自定义内容保留。自定义压缩仅用于主会话；子 Agent 使用内置模板。切换编码模式不会覆盖已有自定义文本。

自定义压缩提示词最多 50,000 字符，必须且仅保留一个 `{conversation}` 占位符，`{output_language}` 可选。自动和手动压缩共用该模板；已有任务及其恢复使用启动时的自定义内容。

左侧标题区菜单可查看“完整提示词”“压缩提示词”和“预览请求”。压缩提示词预览只读展示当前草稿生效的内容：关闭定制能力或自定义为空时显示内置默认，否则显示自定义全文。预览不会提前包含未来操作才发现的子目录规则。

### 资料

向 Agent 提供“设置 > 通用”中的助手名称、角色、自定义指令和用户信息，帮助它按你的偏好回答。此项没有独立工具，也不赋予修改资料的能力；通过工具修改资料需要“修改配置”。子 Agent 是否接收资料，由自身能力及项目限制共同决定。

### 运行环境

向 Agent 提供在“设置 > 环境”中选中的系统、日期、目录、命令环境和自定义环境信息。此项只提供说明，不会安装程序或开启执行权限。

内置 rg 的说明需要同时开启“执行命令”和环境设置中的“内置命令”。关闭“运行环境”不会移除已经可执行的程序。自定义环境信息为空时的后台检测规则见[运行环境与环境变量](#运行环境与环境变量)。

### 项目信息

向 Agent 提供当前项目名称、源文件夹及路径使用说明，没有独立工具。关闭后，项目源文件夹仍作为工作目录和授权判断的依据；项目提示词独立控制，不随此项关闭。

### .env

决定执行命令和自定义工具时是否额外加载应用数据目录 `.env` 中的变量。文件在“设置 > 环境”中编辑。

此项没有独立工具。关闭后仍保留系统继承的环境变量，不清空 `.env` 文件，也不改变模型连接或共享 MCP 服务自身的配置。

### 后台工具

允许耗时的内置、自定义或 MCP 工具调用转到后台，让 Agent 查看、等待或取消。以下工具相互依赖，作为一组启停，不能逐个选择。关闭后，新调用等待完成再返回；已开始的调用不会因此取消。

| 工具 | 功能 |
| --- | --- |
| `read_call` | 查看本会话后台调用的状态、进度和终端信息。 |
| `read_call_output` | 按段读取后台调用的输出和结果。 |
| `wait_call` | 等待指定调用结束或等待超时。 |
| `cancel_call` | 请求取消指定后台调用。 |
| `write_call` | 向交互式终端发送文本、按键或调整尺寸。 |

`write_call` 需要启用“执行命令”或选中的交互式自定义工具。终端必须在启动时创建，不能事后给普通命令补接输入。子 Agent 的后台任务由“子 Agent”能力单独管理。

工具繁忙时会自动排队，无需重复提交。等待或执行较久的调用会返回编号，供 Agent 查看后续结果。

### 计划

提供 `write_todos`，让 Agent 建立和更新当前任务的计划及完成状态。适合多步骤任务；计划本身不执行命令或修改文件，实际工作仍需对应能力。

### 执行命令

让 Agent 通过系统命令运行程序、脚本、搜索、测试和构建。工具按实际命令程序命名，例如 macOS 的 `zsh`、Windows 的 `pwsh` 或 `powershell`；需要系统中存在可用的命令程序。

内置 rg 可用于文件和文本搜索，无需另行安装。脚本依赖的 Python、Node.js 等程序仍需自行准备。后续终端输入还需要“后台工具”；应用 `.env` 变量由 `.env` 能力独立控制。命令执行遵循当前对话的授权模式。

### 网络访问

提供 `http_request`，用于 HTTP/HTTPS 请求、接口调用、上传和下载。需要目标地址可访问，以及请求所需的认证信息；它不是浏览器自动化工具。

本工具可自行上传或下载文件，不依赖“文件读”“文件写”两个工具组，但文件访问仍遵循授权规则。MCP 连接和命令中的网络访问不由此开关控制。

### 修改配置

提供 `update_config`，让 Agent 按你的要求修改支持的应用设置，例如主题、字号和资料。目前只能修改应用设置中的受支持字段，不能通过它任意改写项目、模型或 MCP 配置文件。

不依赖“文件写”。“允许只读”和“严格授权”模式下，每次调用都需要确认；“完整访问”模式下直接执行。

### 用户交互

提供 `request_user_input`，让 Agent 弹出问题，供你选择选项或输入答案。适用于缺少信息、需要澄清或选择方案的情况；你可以取消，普通问题也可超时返回。

此项不依赖后台工具。关闭后 Agent 仍可在聊天中提问，但不能使用这个交互弹窗；工具执行前的授权确认不受此开关影响。

### 等待

提供 `sleep`，让 Agent 等待一段时间后再继续，例如稍后检查网页或聊天回复。`seconds` 必填，只接受 1～300 秒的整数；`summary` 可填写等待原因。完成时返回实际等待秒数，之后仍需调用相应工具检查变化。

独立于“执行命令”和“后台工具”，在项目和子 Agent 的能力设置中单独启停。等待直接完成后返回，不在 10 秒后转后台；停止运行会取消等待。

聊天中的等待条目显示时钟图标和剩余秒数；倒计时到零后等待实际结果，完成后显示耗时。

### 文件读

直接读取和检查本地文件，不依赖“执行命令”。读取项目外文件是否需要确认，由对话授权模式决定。

| 工具 | 功能 |
| --- | --- |
| `read_file` | 读取单个 UTF-8 文本文件，可指定行范围；不读取二进制内容。 |
| `read_multiple_files` | 批量读取多个文本文件，分别返回结果。 |
| `view_image` | 查看一张本地图片，将画面提供给当前模型。 |
| `view_multiple_images` | 一次查看最多 10 张图片，逐张标明路径，单个失败不影响其他图片。 |
| `list_directory` | 列出目录的直接子项。 |
| `directory_tree` | 分页查看目录结构，最多展开 64 层，不跟随符号链接。 |
| `get_file_info` | 查看类型、字节大小、时间；自动补充图片尺寸与方向、音视频时长和轨道信息。 |

图片工具需要当前模型支持视觉且开启视觉能力配置；支持 PNG、JPEG、WebP，不依赖“执行命令”。原图直接发送，不缩放或重新编码；单图最多 8 MiB，批量图片数据合计最多 16 MiB。

`get_file_info` 只读取文件信息，不识别画面内容；无需安装额外的媒体分析程序。

文本搜索可使用“执行命令”中的 rg；“文件读”本身没有独立搜索工具。

### 文件写

直接创建、修改、移动或删除本地文件，不依赖“执行命令”。可单独选择所需工具；需要先检查原文时，还应启用合适的读取工具。项目外写入通常需要确认，详见[工具与授权](#工具与授权)。

| 工具 | 功能 |
| --- | --- |
| `apply_patch` | 按原文上下文定位并修改文件，支持只预览不写入。 |
| `write_file` | 创建文本文件，或明确选择覆盖整个已有文件。 |
| `restore_file_edit` | 撤销有记录的整次 `apply_patch` 或 `write_file` 操作；恢复资料必须仍可用，遇到冲突不会直接覆盖。 |
| `get_file_edit_diff` | 查看 Agent 记录的文件改动，不等同于查看 Git 工作区差异；该工具本身只读。 |
| `create_directory` | 创建目录及所需的父目录。 |
| `move_file` | 移动或重命名文件、目录。 |
| `delete_file` | 删除文件或目录。 |

### 记忆

保存全局或当前项目的偏好、事实和经验。以下四项可独立选择，不互为前提。

| 子项 | 功能与依赖 |
| --- | --- |
| 自动召回 | 根据当前用户消息查找相关记忆并提供给模型；不调用工具，也不自动写入记忆。 |
| `read_memory` | 主动搜索或列出全局和当前项目的记忆。 |
| `save_to_memory` | 创建或更新记忆，选择全局或当前项目范围。 |
| `forget_memory` | 按记录 ID 删除记忆；不知道 ID 时可先查询。 |

只选“自动召回”即可使用相关旧记忆；关闭自动召回后，仍可启用查询或保存工具。取消选择不会删除记录，可在“设置 > 记忆”搜索、编辑或删除。

### 自定义工具

将你配置的程序或脚本作为工具提供给模型。需要准备对应的程序、依赖和账号；不依赖“执行命令”，交互式工具还需“后台工具”。配置和启用方法见[自定义工具管理](#自定义工具管理)。

### MCP

每个 MCP 服务分别选择“全部／定制／关闭”。全部动态包含新工具；定制只使用勾选的工具。切换模式保留定制选择。

需要在“设置 > MCP”中启用对应服务并成功连接。项目勾选不会自动启动全局停用的服务。工具的作用、参数、依赖软件和账号由服务决定；它们不依赖同名的内置文件或网络工具开关。停用或不可用的已选工具仍可取消。

### 子 Agent

将独立任务交给其他 Agent，适合并行调查和分工。以下工具相互依赖，作为一组启停，不能逐个选择。

| 工具 | 功能 |
| --- | --- |
| `start_subagent` | 启动一个允许使用的子 Agent。 |
| `read_subagent` | 查看子任务的状态和过程。 |
| `wait_subagent` | 等待子任务进展、结束或需要确认。 |
| `cancel_subagent` | 取消指定子任务。 |

在“设置 > 子 Agent”中配置并启用子 Agent。项目和子 Agent 中选择“全部／定制／关闭”：全部采用已启用且配置完整的定义；定制只采用勾选的可用定义，名单为空则无法启动。定制列表默认收起，展开后直接显示条目，不提供搜索。全局关闭的定义不能被局部重新启用。此能力不依赖“后台工具”。

子 Agent 使用各自的能力配置，可继续调用其他子 Agent，但候选范围不能超出最初项目允许的范围。“限制子 Agent 能力”另行限制所有层级子 Agent 的上下文、工具和技能：勾选后只允许双方都启用的能力；未勾选时按子 Agent 自身配置执行。子 Agent 只收到委派任务，不自动获得整个主对话。

在“标识”标题右侧可选择模型和参数预设。默认“跟随父 Agent”，沿父级使用最近指定的模型及预设；选择独立模型后，后续创建的子任务使用该选择，清除选择即可恢复继承。修改子 Agent 定义不改变已有子任务的模型绑定；指定模型或预设失效时会报错，不自动换用其他模型。

### 技能

向 Agent 提供可用技能的名称、用途和说明文件位置，或让你通过 `/name` 快捷调用。技能是操作说明，没有独立的调用工具，也不会自动赋予文件、命令或网络能力。

“技能”使用“全部／定制／关闭”。定制列表默认收起，不提供搜索。切换全部或关闭不会清空定制选择。插件技能在对应插件分组中选择，不受普通技能分组控制。

设置页依次显示“快捷方式”“模型可用”“脚本免审”，前两项与项目中的“快捷”“模型”对应，是全局技能（包括插件技能）的上限；项目和子 Agent 不能重新启用全局关闭的用途。子 Agent 只配置模型使用范围。`.agents/skills/` 中的项目技能不受全局可用性开关控制，在项目中选择。

主动调用会直接发送技能文件原文和来源路径，调用后的文字作为独立的用户需求；可展开技能记录查看实际发送内容。模型自主读取技能说明或附带资料需要 `read_file`、`read_multiple_files` 或可读取文件的“执行命令”；技能中的脚本还依赖命令程序、运行环境、所需工具和账号。选择技能不代表这些依赖已经满足。在“设置 > 技能”管理全局来源和可用范围；项目技能放在源文件夹的 `.agents/skills/` 下。导入、同名选择和编写方法见[技能手册](./AGENT_SKILLS.zh-CN.md)，安装要求见技能自己的 `SETUP.md`（如有）。

## 模型

支持 OpenAI 兼容和 Anthropic 兼容服务。在“设置 > 模型”中管理模型，在消息输入框底部切换使用。

模型编辑窗口中的名称、能力、上下文限制、额外参数和推理选项先保留为草稿，点击“保存”后统一生效；点击“取消”或关闭窗口会放弃本次修改。

按模型实际支持情况设置“视觉”和“工具调用”。关闭“工具调用”后，模型不能调用内置工具、MCP 工具或子 Agent；资料、运行环境、项目信息、技能目录和自动记忆召回仍按能力设置提供，已保存的选择不变。

## 工具与授权

项目“定制能力”选择可用工具，模型的“工具调用”决定能否调用。各项用途和依赖见[项目与能力](#项目与能力)。

项目设置的文件夹下方，左侧选择默认工具权限，右侧选择模型及推理选项。新对话继承项目权限，也可在输入框旁单独切换；修改项目默认权限不影响已有对话。未配置时使用“允许只读”，无需开启“定制能力”。

对话支持三种工具访问模式：

- **允许只读**：默认模式，可直接读取项目外文件；项目外写入和无法确定为受支持只读操作的命令需要确认。
- **严格授权**：项目外读取也需要确认；只自动放行目标在项目内的受支持只读命令。
- **完整访问**：跳过执行前授权，可在输入框旁的工具权限菜单中切换为“允许只读”或“严格授权”；切换不打断已经开始的操作。

外部操作结果不确定时，仍需确认是否重试。等待确认的会话不能发送消息、编辑历史、重新生成或压缩，其他会话不受影响。

子 Agent 可在后台处理任务。点击其状态条可查看任务内容、工具调用和结果；主任务结束时，未完成或等待批准的子 Agent 会被取消。

## 运行环境与环境变量

“运行环境”中的“内置命令”默认开启，向 Agent 提供内置 rg 的使用说明。“检测系统环境”可更新系统命令信息，无需检测内置 rg。

“自定义环境信息”默认开启。启动时若已勾选且内容为空，会在后台检测并填入，不阻塞启动；已有内容不覆盖，检测期间取消勾选则不填入结果。

在“设置 > 环境”中编辑应用 `.env`，为命令、自定义工具和技能脚本准备变量。是否传入这些变量由相应 Agent 的 `.env` 能力决定。

## 自定义工具管理

内置技能 `tool-manager` 可指导模型创建、修改和排查自定义工具，包含格式参考和 Python 示例模板。启用该技能及所需的文件操作能力后，可直接要求模型“为当前项目创建一个自定义工具”。测试脚本还需命令执行能力和对应运行环境；生成后，“全部”模式会在后续运行加载；“定制”模式需先在能力设置中选中工具。

“设置 > 工具”左侧上方是“内置工具”和“MCP”，右侧分别按能力和服务器分组。横线下方是自定义工具目录树：全部、系统、用户和添加的目录。点击分组名称在右侧查看工具列表，前方的方框箭头负责展开或收起；点击列表中的工具进入详情。点击详情标题可定位目录。也可展开工具包查看文件和预览文本；用户和添加目录中的工具可新增、双击编辑、删除及排序，删除会将整个工具包目录移到废纸篓。

“添加目录”直接引用外部工具目录，支持修改显示名称、排序和移除；名称在回车或失焦时保存，移除不会删除文件。选中用户或添加的目录分组后，右侧标题栏提供“添加”和“导入”，均写入当前来源目录。系统目录随应用更新，预置 `file_sha256`（文件 SHA-256）和 `json_format`（JSON 格式化），在能力设置中选中即可使用，无需导入。

每个工具目录包含显式声明 `"version": 0` 的 `TOOL.json` 和脚本或资源。用户工具保存在应用数据目录的 `tools/`；项目工具放在源文件夹的 `.agents/tools/`，仅供对应项目使用。编辑器配置名称、描述、JSON 参数规则和执行命令，不生成业务脚本或安装依赖。

选中“用户”或添加的目录分组时，右侧标题栏显示“＋”新增和“导入工具”按钮。导入可多选目录，默认打开内置示例目录，提供文本读取和百度 AI 搜索示例，均使用 Python 3 标准库。百度搜索另需联网和 `BAIDU_SEARCH_API_KEY`，配置见包内 README。导入会复制到所选工具来源目录，不覆盖已有工具。

详情页的“编辑信息”和“编辑参数”打开同一窗口，分别进入“基本信息”和“参数”页，切换时保留草稿。参数页支持“参数 / 源码”切换，可增删改参数，设置类型、必填、描述、枚举和范围等约束，并展开对象、数组编辑子参数。单个参数在窗口内编辑，应用后返回列表；点击工具“保存”后统一生效，放弃未保存修改需确认。脚本需自行同步修改。高级引用和组合定义使用源码编辑，其他未编辑的属性保持不变。默认值仅作说明，不会在调用时自动补入。

执行命令中的包内脚本路径可点击定位到左侧文件列表。文件不存在时，可确认创建空文件及缺失目录；系统工具只读，已有文件不会被覆盖。

在工具详情中启用或停用工具。项目和子 Agent 的“自定义工具”分组选“全部”时，新增工具自动纳入；选“定制”时需手动勾选，条目按来源分组，每行可显示多个工具并随宽度自动换行；选“关闭”时不使用工具并保留选择。子 Agent 使用独立选择，可开启“使用当前项目工具”，并遵循项目限制。同名时优先使用项目源文件夹顺序中的有效启用项，其次为用户工具、按顺序排列的外加目录和系统工具。

命令在工具目录运行，相对路径从这里解析，例如 `scripts/run.py {{args}}`。`.py` 入口自动选择可用的 Python 3，也可明确指定解释器。独立参数 `{{args}}` 接收完整 JSON；`{{tool_dir}}` 表示工具目录绝对路径。命令只启动一个程序及固定参数，不支持管道或重定向。程序的标准输出作为结果返回模型；大段输入宜通过文件传递。

“交互式终端（PTY）”用于需要后续输入的程序，依赖“后台工具”，无需开启“执行命令”。普通文本结果不需要开启它。超时留空表示不限时，填写正整数秒可限制执行；等待输入也计入超时。取消或超时会终止进程树，但不会撤销已经发生的修改。

## MCP 设置

在“设置 > MCP”中添加和编辑服务，支持 stdio、HTTP 和 SSE。服务需启用并成功连接，模型需开启工具调用，项目需允许使用对应工具。

stdio 服务的“工作目录”留空时使用当前用户主目录；需要在其他目录运行时，填写该目录的绝对路径。

停用的服务仍可编辑；编辑运行中的服务会先停止它。“设置 > 工具”的工具目录按服务展示工具，项目中可进一步选择可用工具。

## 附件与语音输入

附件发送后会保存本地副本，原文件移动或删除不影响查看。默认只供当前一轮使用，点亮固定按钮后可在同一会话的后续轮次继续使用。

支持提取文本文件、PDF 和 docx 的文字。图片需要模型开启“视觉”；纯文本模型无法接收或查看图片内容。不支持的文件会标明未发送给模型。

点击麦克风按钮可调用 Windows 语音输入或 macOS 听写。开始、停止和识别语言由系统控制；macOS 需先在“系统设置 > 键盘 > 听写”中启用。确认系统听写已开始，输入结束后检查文字再发送。Anas 不录制或保存音频。

语音回复直接连接微软 Edge 在线语音服务，需要联网，待朗读文本会发送给微软。音色和语速可在设置中调整；音频仅在内存中暂存，停止播放或切换会话会取消未完成的合成并释放待播音频。

自动朗读随主模型正文分段播放。后续工具调用、等待审批或子 Agent 工作出现时，尚未开播的回复会取消朗读；已经开播的回复继续播放，包括分段之间等待合成的情况。新一轮主模型开始输出正文时，停止旧音频并切换到新回复；思考和纯工具调用不会打断已经开播的回复。最终消息不会重复播放已朗读或已取消的内容。

## 会话与上下文

Agent 页面左侧为项目和会话，中间为对话；帮助、子 Agent 和“文件改动”在右侧工作区打开。拖动分隔线调宽，或放大右栏；窄窗口使用可调宽的抽屉。收起右栏或切换会话会保留标签和查看位置。关闭子 Agent 标签不会停止任务。

帮助、文件改动、子 Agent 和插件均可右键点击标签，选择「移到独立窗口」；通过独立窗口标题栏图标移回侧栏。切换位置保留页面状态和连接。“文件改动”全局只打开一份，跟随当前项目和会话，标题显示项目名称；切换项目不会收起侧栏，已独立显示时再次点击入口会聚焦原窗口。切换上下文后重新选择运行和文件。子 Agent 独立窗口仍绑定原项目和会话，移回时自动定位原会话。

拖动右侧标签可调整顺序，靠近标签栏边缘会自动滚动。明显拖离标签栏后松手可移到独立窗口，按 Esc 取消。切换会话、收起展开和移出再移回会保留顺序；仅支持侧边栏的插件不能拖出。

独立面板进入全屏后，操作按钮保留在可拖动的浮动工具栏中；插件也可提供带分组的工具栏菜单。跨显示器移动和程序自动适配窗口与用户主动调整大小分开处理，避免无意改变插件内容尺寸。

在“文件改动”中选择比较范围和文件，查看只读差异。顶部工具可切换行内／左右对比、折叠未修改区域。Git 比较支持工作区、暂存区、分支、标签和提交。历史原文不可用、二进制或超过 1 MB 的文件会提示无法显示差异。

“回合改动”显示当前会话有记录的文件修改，包含子 Agent 的改动，非 Git 目录也适用。默认比较该回合首次修改前与最后修改后的内容；“对比当前文件”改为比较当前磁盘内容，可能包含后续修改。消息下方的“本回合改动”可直接定位该回合。

点击“审核所选范围”可让 Agent 审核差异；发出的消息会显示实际审核指令和差异内容。

会话自动保存，侧栏显示用户发送消息的轮数；较早的消息可按需加载。执行过程显示工具调用、等待批准、失败原因和耗时。页面自动跟随新输出；向上滚动或展开详情时暂停，滚回底部或点击“滚动到底部”可恢复。

长对话会自动压缩上下文，也可通过输入框旁的上下文指示器手动压缩。指示器分类显示估算用量，预留输出空间单独显示，不计入已用上下文。

上下文超限时，过长的工具结果可缩短为预览，并附上完整结果文件的路径；原始聊天记录保留。文件位于数据目录的 `db/conversations/<主对话ID>/tool_results/`，随应用备份保存、随整个对话删除；清缓存不影响这些文件。

项目编辑窗口的“预览请求”可检查当前项目将提供给模型的上下文和工具。

## 插件

「设置 → 插件」的概览按提示词、技能、工具分组展示；悬停名称查看简介，点击查看并复制只读详情。技能显示 `SKILL.md` 中的名称，工具显示模型实际使用的名称及完整参数；提示词和技能正文可切换预览／源码。插件停用或后台未启动时也能查看，预览不会启动后台。

「设置 → 工具 → 插件」按插件展示工具目录，可查看和复制模型工具定义。停用的插件仍可查看，浏览目录不会启动插件后台。

插件提供的工具、技能和提示词在项目和子 Agent 中按插件集中选择「全部／定制／关闭」。全部包含新增贡献，定制只包含明确选择，关闭保留定制选择。未定制项目使用已启用插件的可用贡献；定制项目中新插件默认关闭。插件技能的快捷方式／模型可用性仍受技能页控制。普通技能开关不控制插件技能；缺少依赖工具时会显示原因，不自动勾选工具。插件设置页负责安装、整体启停、自身配置和内容预览，不重复设置能力开关。

项目和子 Agent 选择的插件工具可在没有插件页面的情况下调用，文本、JSON 或图片结果沿用普通工具的对话显示。停用后不能调用；更新插件后按当前工具定义使用，不因版本变化要求重新建对话。取消或超时只通知后台停止当前调用，不会因此终止整个插件后台；发出取消不代表操作已经停止，仍以后台回执为准。

Anas 3.3.8 起仅运行插件 API 2 的插件，旧版插件须先更新。RDP 插件 0.1.9 需要 Anas 3.3.13 或更新版本，请先更新宿主，再安装插件。

在“设置 > 插件”中点击“安装插件”，默认筛选插件 ZIP 文件；选择已构建插件目录中的 `PLUGIN.json` 时，切换到插件清单筛选项。ZIP 无需手动解压，清单须位于压缩包根目录，或唯一的顶层文件夹中；选择 `PLUGIN.json` 会安装它所在的整个目录。也可将一个 ZIP、`PLUGIN.json` 或插件目录拖入插件页面；目录根部须包含 `PLUGIN.json`。拖拽安装沿用相同的校验和覆盖确认，安装或确认期间不接收重复拖入。对话顶部的插件菜单只显示有首页的已启用插件，按首页打开位置显示在右侧工作区或独立窗口；没有可打开首页时隐藏菜单入口。无首页插件在设置中管理，工具、技能和提示词按能力设置生效，无需手动启动。纯界面插件没有后台进程；可选后台在首次调用时自动启动，也可在设置中手动启动或停止。

同 ID 插件已安装时，会显示新旧版本并询问是否覆盖。确认后关闭该插件的页面和后台，保留启用状态并替换安装包。默认不勾选「删除插件数据」，原配置、凭据等数据会保留；勾选后清除该插件的数据。取消不会影响现有插件；安装失败会尝试恢复旧包和数据，无法恢复时会保留文件并报告位置。

收起面板、切换会话或进入设置保留插件页面状态，关闭标签会销毁该页面。Windows／Linux 关闭主窗口会退出应用，同时关闭独立面板和插件后台；macOS 关闭主窗口只隐藏，使用“退出”结束应用。通过标签右键菜单「移到独立窗口」和独立窗口标题栏「移至侧边栏」切换位置；插件保存界面状态并在目标页面恢复，后台连接继续运行。交接失败会保留原页面。每个插件最多保留一份首页，再次启动会显示并聚焦它所在的侧栏或窗口。其他业务页面共享已保存的数据和后台，各自保留自己的页面内容。刷新窗口会释放其中的页面，后台资源仍由插件管理，重新打开时按插件能力恢复。在「设置 → 插件」选中插件，可设置首页打开位置，停用时也可修改；关闭已有首页后，下次创建时生效，固定位置的插件不能切换。停用或卸载会关闭页面和后台。卸载默认保留数据，重新安装同 ID 后可继续使用；勾选「删除插件数据」则同时删除该插件的配置、凭据及其他数据，已有备份不受影响。

内置“用量仪表”默认启用，在设置按钮上方显示当前输入框所选模型供应商的账户额度、余额或密钥消费，支持立即刷新。默认紧凑模式，一行显示套餐剩余额度或带币种的余额；空间不足时隐藏套餐周期短标签，优先保留百分比，空间足够时恢复；悬停按组查看详情与更新时间。支持 MiniMax Token Plan（5h 限额、周限额及各自重置时间）、智谱 / Z.ai（Coding Plan 的 5 小时额度、每周额度及独立 MCP 月额度，以接口返回为准；国内智谱普通 API 显示人民币可用余额，展开查看累计充值、累计消费及冻结余额，缺失字段不显示）、DeepSeek（可用／赠金／充值余额）、Moonshot/Kimi（可用／代金券／现金余额，国内人民币、国际美元）、OpenRouter（当前 API Key 剩余额度及累计、日、周、月消费）。OpenRouter 的“未设上限”仅表示密钥未配置额度上限，不代表账户余额充足；账户总余额需要管理密钥，本插件不查询。设置中的插件概览按界面语言列出厂商及说明。点击仪表右侧箭头展开进度条与时间信息，再次点击收起；样式自动保存，重启后保留，无需进入设置。MiniMax 当前接口不提供套餐到期日，重置时间不是套餐到期时间。按 API URL 识别供应商；智谱 / Z.ai 的 /api/coding/paas/v4 或 /api/anthropic 路径查询套餐状态，国内智谱的普通 /api/paas/v4 路径查询账户余额，国际普通 API 及其他路径隐藏。两类查询分别缓存，使用已配置的供应商密钥，无需控制台登录，不根据密钥格式猜测套餐类型。智谱余额不包含资源包和 Coding Plan 额度，余额为零也不直接判定模型不可用；余额查询使用控制台接口，目前无公开接口文档。匹配后立即显示加载状态，无需等待查询完成；切换模型或凭据时清除旧读数，同一上下文刷新保留原读数。MiniMax 的“5h 限额”和“周限额”是两个独立额度，紧凑和展开模式均显示剩余额度，周额度计入套餐加成，例如“5h 90% · 周 148.5%”。进度条表示剩余占实际总额度的比例；总额度、已用和加成说明放入详情，重置倒计时仍直接显示。公开接口的百分比精度可能造成与官网的小幅差异。自动查询缓存 5 分钟，失败时保留上次读数并显示提示和更新时间。这些是供应商账户或密钥数据，不是当前对话的 token 消耗。展示内容由插件 HTML 定义，样式、主题和字号由宿主统一提供。插件随应用更新，可在“设置 → 插件”停用，不能卸载。手动停止或备份停止后台后，可在插件设置中重新启动。

百炼 / Qwen 中国站支持 `dashscope.aliyuncs.com` 和 `token-plan.cn-beijing.maas.aliyuncs.com`。需先安装 `bl`（`npm install -g bailian-cli`），插件使用 bl 当前配置；未登录或会话失效时点击仪表内“登录百炼”，账户不匹配时点击“切换账户登录”，在浏览器选择对应账户，完成后刷新。登录更新 bl 配置，可能由 CLI 创建普通 API Key，不更改 Anas 的模型配置；等待期间可取消。Token Plan 个人版按已配置 Key 的首 15 位和尾 15 位与控制台脱敏 Key 核对，显示实际返回的 5 小时、周或月剩余额度、重置时间、套餐规格、状态、到期时间及自动续费状态。未返回额度窗口时提示未提供额度，保留套餐信息，不推断为无限额度。普通 Key 通过详情完整匹配，显示当前模型的免费额度（不是账户余额）及该 Key 所属工作空间近 7 天在线调用和用量。统计可能有聚合延迟。未安装、权限不足、查询失败、Key 不匹配均显示错误；百炼失败时清空读数，避免误用其他账户缓存。国际站与团队版专用地址暂不支持。

展开视图直接显示主要额度、余额和重置时间，更新时间右侧的详情图标收纳账户、套餐、余额构成及消费明细。百炼普通 API 保留当前模型免费额度和近 7 天调用数，工作空间、额度到期和用量明细放入详情；智谱 Coding Plan 保留重置倒计时，精确日期放入详情。MiniMax 保留剩余额度及重置倒计时，悬停查看精确重置时间；总额度、已用和加成说明放入详情。悬停图标预览，点击固定浮层后可选择复制文字，再次点击、点击外部或按 Esc 关闭；查看详情不会重新查询，无附加资料时不显示图标。查询失败、明确的余额不足和套餐失效等异常仍直接显示；紧凑视图的悬停提示保留完整信息。

插件替换或卸载中途退出时，下次启动会先恢复未完成的操作，并清理已完成操作的残留。恢复材料不会被清理缓存或临时文件删除；若日志损坏、目录冲突或恢复失败，启动恢复界面会提示保留位置，解决问题后可重试。

插件与其数据包含在应用备份中；备份会先停止后台，恢复不会自动重启。带后台的插件可使用当前用户的系统权限，应安装你选择信任的插件。插件出错会单独显示在插件设置中，不要求重置应用配置。

## 本地数据与备份

**4.0 数据变更：升级后，旧项目及其设置、输入历史（含置顶输入）会从界面中消失，可按下述方法手动恢复；旧对话记录及全部长期记忆（含项目记忆）不再保留。** 程序不提供自动迁移，也不支持导入 4.0 之前的备份。全局设置、项目源文件和用户包不变；插件独立数据改放 `db/plugins/`，旧 `plugins_data/` 不自动读取，可手动移动恢复。旧布局文件暂留磁盘，但新版不读取、不自动删除，也不纳入新备份；可通过“数据清理 → 未知文件”查看并清理残留（默认不选中）。

恢复项目和输入历史：建议在开始使用 4.0 创建新数据前，完全退出 Anas，备份原文件，再将数据根目录中的两个文件移入同一数据目录的 `db/`（没有则创建）：

- `projects.json` → `db/projects.json`：恢复项目定义和项目设置。
- `input_history.json` → `db/input_history.json`：恢复输入历史和置顶输入。

这两份文件沿用现有 v0 格式，无须修改内容；重新启动后即可读取。如果 `db/` 中已有同名文件，先另行备份；覆盖会替换新版中的对应数据，不会自动合并。此操作仅恢复项目和输入历史，不恢复旧对话或记忆。

恢复插件数据：完全退出 Anas 并备份后，将原 `plugins_data/` 整体移动为 `db/plugins/`，目录内部结构不变。如果目标目录已存在，先另行备份；整体替换不会合并两边的数据。

头像资源改放 `config/assets/`，旧根目录的 `assets/` 不再读取；未手动恢复时使用默认头像。需要保留自定义头像时，完全退出 Anas 并备份后，将原 `assets/` 整体移动到 `config/assets/`，内部文件无须修改；目标已存在时先另行备份，整体替换，不合并。

默认数据目录为 `~/.gale<程序名>/`，标准 Anas 使用 `~/.galeAnas/`。复制并重命名程序可使用独立的数据目录。

也可启动时指定目录，例如 `Anas.exe "D:\Anas Data\Research"` 或 `--data-dir <路径>`。相对路径以启动目录为准，不能使用文件系统根目录。

备份保存为 zip 文件，默认位置为当前系统用户的“文档”目录；已经选择过保存目录时继续使用该目录。备份包含用户工具和技能；项目源文件夹及外部引用的技能需另行备份。不包含运行日志、临时文件、开发请求追踪、应用缓存、界面缓存和登录状态，以及旧布局残留。

“设置 > 通用”中的“数据清理”隐藏已确认没有可清理内容的项目。会话清理保留置顶、运行中和等待批准的会话。“未知文件”默认不选中，可展开查看白名单外的路径，目录以 `/` 结尾；清理包含旧布局残留和数据根目录中的备份文件。需要手动恢复的旧项目、输入历史、插件数据和头像应先移到新目录或另行备份，再清理对应旧文件。`cache/` 只由缓存清理处理，`db/conversations/` 只由对话删除处理。

从对话菜单删除整个对话时，无须先修复已缺失、损坏或版本不匹配的会话数据库；删除会同时清理该对话的附件、文件修改恢复材料、长工具结果和临时草稿。如果系统拒绝删除文件，会保留删除进度，解除占用或权限问题后可重试。

## 故障排查

“设置 > Dev”提供开发者工具、日志查看，以及“控制台方式启动”。后者会保留当前数据目录并重启应用，在系统终端显示启动和运行输出。

- **模型调用失败**：检查服务地址、模型名、密钥和网络连接。
- **技能失败**：检查技能说明、环境变量和所需程序。
- **MCP 工具未出现**：确认服务已启用并成功连接、模型已开启工具调用，并检查项目工具选择。
- **操作等待确认**：按提示允许或拒绝；结果不确定时，只在接受可能重复执行的情况下重试。

### 启动恢复

启动加载失败时，恢复页列出出错文件，可查看错误详情、打开日志目录，并选择：

- **修复**：用默认值修正错误配置项，保留有效设置。能力选择按当前配置格式逐项校验；无法识别的值恢复对应默认值，不转换旧格式的含义，也不因能力配置出错重置整个文件、项目或会话。没有条目默认值的无效选择列表恢复该列表的默认值；无法解析的文件或无法确定身份的项目仍需手动处理。具体修改列在错误详情中。
- **重置**：将所选配置恢复默认。**重置 `db/projects.json` 会同时清空所有项目的会话、消息、执行记录、任务恢复信息和记忆**；对话附件、长工具结果和文件修改恢复材料一并清空；输入历史、其他配置、技能及项目源文件保留。

操作前自动保存原始数据到数据目录旁的 `Anas-Recovery/时间戳-随机后缀/`，保存失败则不修改。处理完成后重新启动。

应用自有持久化数据以显式格式版本 `0` 为当前原点。自动升级和手动修复分别处理：版本缺失、不匹配或自动升级失败，都可以在恢复页尝试“修复”。输入历史和头像资产出错也会在进入主界面前进入恢复页。程序先保全原始数据，再尽力修复配置、输入历史、头像、项目及关联数据库；有效设置、项目身份、会话和记忆尽量保留。无法恢复的数据库保留原样，不阻断其他数据抢救，剩余问题逐项显示。修复不会自动清空项目或会话。

输入历史可逐条恢复有效记录，保留顺序和置顶状态；坏条目保留在原文副本中并报告部分修复。若非空历史完全无法识别，不会将其修复为空列表。没有对应删除日志的项目删除暂存文件也会保留，不阻断项目修复。

头像修复从仍可读取的原图、裁剪图或显示图重建所需资产，修改前保全原文件；没有可恢复图像时报告问题，不自动换成默认头像。导入备份时还会在替换数据前检查头像参数，拒绝不支持的版本或损坏参数；尚无头像参数不影响正常初始化。
