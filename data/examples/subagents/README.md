# 子 Agent 示例

[English](README.en.md)

仅 `general-purpose` 是内置 Agent。以下示例默认不加载：

- `web-researcher`：研究外部信息、核实来源，返回带链接的结论。
- `project-analyst`：只读分析项目文件、代码、配置和文档。

在“设置 > 子 Agent”点击右上方的“导入子 Agent”，可多选此目录中的示例包。导入会复制到用户的 `subagents/`，不覆盖同 ID 或同名包，有冲突或无效包时整批停止；导入后可编辑、关闭或删除。

每个包包含 `AGENT.json`（定义和能力）与 `PROMPT.md`（提示词），也可加入自己的 `skills/`、`tools/`。提示词从设置中的文件树进入编辑。实际可用能力仍受宿主和项目配置约束。

此示例目录随应用更新。修改前请先导入，不要直接编辑或将此目录添加为外部 Agent 来源；已导入的副本不会被示例更新覆盖。
