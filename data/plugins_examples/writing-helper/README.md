# 纯声明插件示例 / Static plugin example

安装 `PLUGIN.json` 后，技能页出现 `proofread`，可使用 `/proofread@plugin:writing-helper` 精确调用。未定制项目会使用已启用插件的技能和写作说明；定制时在对应插件分组选择“全部”，或分别选择 `proofread` 和 `writing-tone`。示例没有页面或后台，不执行插件代码。

Install `PLUGIN.json` to add the `proofread` skill. Invoke it explicitly with `/proofread@plugin:writing-helper`. Uncustomized projects use the enabled plugin’s skill and writing instructions. For customized scopes, choose All in its plugin group or select `proofread` and `writing-tone` individually. This example has no page or backend and executes no plugin code.
