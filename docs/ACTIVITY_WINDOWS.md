# 活动显示目录与虚拟列表

## 数据边界

会话数据库 v3 保留原生执行正文作为唯一权威记录。显示目录只用于展示，不参与执行、审批、模型上下文或结果判断。

正文发布事务同步写入 `agent_display_headers`。显示相关表的触发器只登记本事务内变更的来源身份；`displayTransaction` 在提交前由统一投影消费这些身份，维护 `agent_display_items`、`agent_display_groups` 和各范围的修订。正文、成员归属和组标题一起提交或回滚。工具委派通过有索引的关联表归到唯一子 Agent 入口。

普通追加只更新新成员、相邻边界和受影响的组。当前活动、待审批活动及是否存在思考／工具都走索引定位，不扫描全组、不统计数量。插入／删除回复边界时重分受影响的成员区间。轮次编号在写入时保存；删除重排只影响后续编号。流式正文归观察缓存所有，只有展示状态变化才更新目录；子 Agent 的展示状态沿索引定位的父级链同步到祖先目录，不复制流式正文。重启通过暂态索引清除失去内存正文的展示状态。

普通读取不重建、不转换缺失的显示头。显式修复先保全原数据，再从权威正文重建；离线校验核对显示头与正文。修复比较实际分组、成员归属与元数据，不把重建顺序导致的组 ID 变化判为损坏；错误归属、缺失组和损坏元数据仍须修复。旧会话库不迁移、不回退读取，配置与其他数据库版本不变。

## 读取与分组

1. 展开外层轮次／子 Agent：`ActivityDirectoryReader` 通过外层索引读取独立行和已存组标题。折叠组只有一条记录，不读取成员，也不在读取时分组。
2. 展开过程组：携带 `parentId`，按组索引读取该组完整的轻量成员。详情仍按精确引用单独读取正文。回复、用户引导、子 Agent、摘要保持独立边界。
3. `ActivityDirectoryStore` 对外层和每个组分别串行读取，以需求计数保留请求期间发生的更新。范围版本未变时不重读成员，返回空差量；空差量不排序、不发布界面更新。已可读目录后台检查不切换加载状态。关闭范围取消读取、释放成员并丢弃迟到结果；失败保留上一份可读目录，重试与重连立即替换旧请求。IPC 主动取消返回独立结果，真实错误仍然抛出。
4. 主进程每个会话最多缓存 64 个范围、总计 3,200 万序列化字符；这不是进程内存上限。渲染端只持有展开范围的轻量成员，虚拟化只挂载附近行。没有第二套组成员缓存。

没有活动分页、未读区间、占位回读或“加载后续活动”按钮。普通聊天历史的读取批次独立保留。

## 显示与滚动

每个聊天／子 Agent 面板只有一个 `VirtualTimeline`。将展开的树投影成平铺行，依据视口与测量高度挂载附近行，剩余空间由上下占位高度表示。虚拟化不改变目录是否完整，也不请求分页。

模型流式文本与正式回复共用稳定行身份。思考、工具参数和结果等正文只归属于挂载且展开的详情组件；收起或移出虚拟范围即释放组件和正文引用，展开状态保存在面板界面状态中。

正文流式事件由详情组件独立消费；可见状态不变时，不重新发布轮次展示状态。运行中的过程组标题显示当前步骤：工具名称、描述和参数生成进度与工具条目复用同一组件；思考复用原条目的 `reasoning` 及摘要，不另外翻译；完成后显示整体概括。

最外层从运行开始显示“已用时”，独立标题组件每秒按当前时间减创建时间更新；不写数据库，不触发活动读取或整条时间线重绘。等待期间继续计时；结束后改为“用时”，按终态更新时间固定，包括等待时间，不累加成员耗时。卸载或结束时释放计时器，重新打开按实际时间计算。

内部过程组完成后仍显示“进行了思考和工具调用／进行了思考／进行了工具调用”。设置中的“运行过程展示：展开／收起”控制内部组运行期间的默认状态，默认展开；后续回复首次出现时，其上方的过程组收起一次，不等待整次运行结束。判断只读取外层目录的回复边界；后续文本增量和其他回复不覆盖已结束组的手动选择，后续新过程重新应用运行设置。运行结束时收起尚未结束的组；单工具过程和子 Agent 使用相同边界。再次运行进入新阶段后重新应用设置。“显示轮次信息”默认开启，关闭只隐藏 `round` 与模型耗时，不隐藏恢复、审批和错误信息。两个配置字段缺失按默认值解析，不升级配置格式。

面板统一持有“跟随最新／停留阅读”意图，数据调度器没有滚动接口。跟随时依据当前布局到达末尾；停留时通过行身份与行内偏移保持位置，折叠删除锚点时回到其父组或邻近存续行。正文收起使行内偏移超出新高度时，回到同一行开头。隐藏面板不覆盖高度和锚点，恢复可见时重新定位。关闭浏览器原生滚动锚定，避免两个所有者同时校正位置。

- [界面折叠行为](../src/renderer/src/ui/agent/AgentMessageList.dom.test.tsx)：过程、正文、审批、流式状态与组件释放。
- [Electron 行为](../scripts/electron-activity-window.cjs)：真实布局中的虚拟挂载、首尾可达、正文释放、跟随与暂停、隐藏面板恢复。

10,000 条活动属于普通完整目录的压力样本，不为其维护特殊显示路径。性能结论以隔离数据库和实际 Electron 测试为准，不承诺任意正文大小、设备或远端供应商延迟。
