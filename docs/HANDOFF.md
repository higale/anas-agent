# Anas 5.0 主线交接

更新时间：2026-10-30。公开源码与版本发布见 [GitHub](https://github.com/higale/anas-agent)。

项目目录化已实施：项目定义与界面状态拆分，对话资源位于项目目录中，归属在创建后固定；catalog 与记忆行为保留。此次经用户批准，不提供旧布局兼容、迁移或旧备份恢复。后续[偏好记忆待办](TODO.md)未实施。

旧项目文件不参与新布局的启动、重置或备份，不因其存在拦截启动。重置后的空项目目录由正常启动初始化；缺少可选界面状态时使用默认值，恢复检查不再将其误报为损坏。

项目恢复以可进入程序为交付条件：空 catalog 不依赖预先存在的项目目录；手动修复先保全原件，逐项抢救当前格式的项目与会话，再重建索引。无法恢复的内容隔离到保全副本并报告，不继续阻断活动存储；切换前实际打开存储验证，不迁移旧布局或重放外部操作。

## 主线与范围

- 原生实现来自 Anas Next `553fded16ee7ac1205e9283a37f3fa80e932da12`，保留原 Anas UI、设置和插件操作。Next 保留重构历史，后续开发以 Anas 为准。
- 旧框架快照 `codex/legacy-framework-4.0.9` 固定在 `460f58de4f3d914456e3ca64b6e628e845769ecb`，已推送开发远端并长期保留。
- 本次 GitHub 同步版本为 5.0.3，采用独立源码快照；三个平台的安装包由发布工作流构建和校验。源码同步核对公开提交，安装包发布核对 GitHub Release；开发差异基点跟随实际已发布源码。
- 默认数据目录 `~/.anas`，开发与打包一致，保留 `--data-dir`。不自动发现、导入或清理 `.galeAnas`、`.anas-next`，`electron/` 布局不变。
- **用户已明确决定：5.0 使用全新数据库，移除旧执行库迁移。** 只复制兼容配置、Skills、工具、子 Agent 和插件代码，不复制旧 `db/`，旧对话、记忆、运行记录及旧版整包备份不支持导入。步骤见 [5.0 升级数据说明](../data/help/UPGRADE_TO_5.zh-CN.md)和[英文版](../data/help/UPGRADE_TO_5.en.md)。

## 当前执行与持久状态

- 普通聊天、简单聊天、审核、压缩、子任务、历史编辑和恢复共用原生协调器、NativeRunHost 与一份执行状态。LangChain、LangGraph、Deep Agents、旧执行器、图存储、middleware 及适配依赖已移除。
- catalog 使用 v2，会话库使用原生 v1。消息正文、调用、审批、输入意图、效果和终态按应用合同提交；UI 仅保存界面状态。原生请求支持 OpenAI Chat Completions、Responses 和 Anthropic。
- 启动只校验执行版本；旧库、未知版本和缺失 catalog 的残留会话在写入前拒绝。当前格式自身的备份、手动修复和事务回滚继续保留。
- 旧执行库解析器、转换入口及无使用者 JSON 迁移框架均已移除。当前修复按原生结构识别版本字段错误，旧结构保留并报告，不能只改版本号强行使用。
- 文件修改历史按记录原平台的路径语义校验；执行恢复、续跑和外部清理前仍要求本机路径，不自动映射另一平台路径。当前目录事务可识别同一真实目录的不同路径写法。
- 工具活动、实时事件、审批与追加指令统一关联应用调用 ID；供应商重复 ID 不再覆盖历史调用。现有 v1 展示索引从原生事实事务重建，保留正文与审批决定，不重放工具。无使用者的审批生成算法和结果适配已删除；第三方声明只保留实际复用内容。
- 取消先持久化，再等待执行和资源释放；历史编辑等待受影响任务退出后原子替换。恢复不重放已完成工具操作，不把观察事件当作执行证据。

实现合同见 [NATIVE_EXECUTION.md](NATIVE_EXECUTION.md)，存储见 [CURRENT_STATE_STORAGE.md](CURRENT_STATE_STORAGE.md)，数据兼容边界见 [DATA_MIGRATIONS.md](DATA_MIGRATIONS.md)。
