# Anas 主线交接

更新时间：2026-11-08。公开源码与版本发布见 [GitHub](https://github.com/higale/anas-agent)。

活动显示已改为写入时维护组标题与成员归属，外层、指定组成员和正文按需读取，共用单一虚拟时间线，删除旧活动分页链路。最外层运行期间由界面动态显示“已用时”，结束后固定显示“用时”；内部推理／工具组保持原标题，后续回复一出现就收起前面的过程组，之后保留手动选择。设置支持运行过程展开／收起和轮次信息开关。经用户批准，会话库改为 v3，用户自行清空现有对话，不迁移或自动删除旧库。后续审核补齐了子 Agent 流式展示状态向祖先目录的同步，并消除了重建组 ID 变化导致的修复误报；数据格式不变。详见[显示架构](ACTIVITY_WINDOWS.md)。

项目目录化已实施：项目定义与界面状态拆分，对话资源位于项目目录中，归属在创建后固定；catalog 与会话版本保持原值。此次经用户批准，不提供旧布局兼容、迁移或旧备份恢复。偏好记忆支持前台主动写入和后台模型提取：全局／项目 Markdown，设置 → 记忆明确选择后台模型并编辑全局正文，工作区菜单的项目记忆面板查看和编辑项目正文，标题栏活动面板查看处理过程。旧记忆表不读取、不迁移、不清理，新建 catalog 不创建旧记忆表。详见[存储设计](CURRENT_STATE_STORAGE.md#后台偏好记忆)。

旧项目文件不参与新布局的启动、重置或备份，不因其存在拦截启动。重置后的空项目目录由正常启动初始化；缺少可选界面状态时使用默认值，恢复检查不再将其误报为损坏。

项目恢复以可进入程序为交付条件：空 catalog 不依赖预先存在的项目目录；手动修复先保全原件，逐项抢救当前格式的项目与会话，再重建索引。无法恢复的内容隔离到保全副本并报告，不继续阻断活动存储；切换前实际打开存储验证，不迁移旧布局或重放外部操作。

## 当前执行与持久状态

- 普通聊天、简单聊天、审核、压缩、子任务、历史编辑和恢复共用原生协调器、NativeRunHost 与一份执行状态。LangChain、LangGraph、Deep Agents、旧执行器、图存储、middleware 及适配依赖已移除。
- catalog 使用 v2，会话库使用 v3。消息正文、调用、审批、输入意图、效果和终态按应用合同提交；UI 仅保存界面状态。原生请求支持 OpenAI Chat Completions、Responses 和 Anthropic。
- 启动只校验执行版本；旧库、未知版本和缺失 catalog 的残留会话在写入前拒绝。当前格式自身的备份、手动修复和事务回滚继续保留。
- 旧执行库解析器、转换入口及无使用者 JSON 迁移框架均已移除。当前修复按原生结构识别版本字段错误，旧结构保留并报告，不能只改版本号强行使用。
- 文件修改历史按记录原平台的路径语义校验；执行恢复、续跑和外部清理前仍要求本机路径，不自动映射另一平台路径。当前目录事务可识别同一真实目录的不同路径写法。
- 工具活动、实时事件、审批与追加指令统一关联应用调用 ID；供应商重复 ID 不再覆盖历史调用。当前格式的索引修复从原生事实事务重建，保留正文与审批决定，不重放工具。无使用者的审批生成算法和结果适配已删除；第三方声明只保留实际复用内容。
- 取消先持久化，再等待执行和资源释放；历史编辑等待受影响任务退出后原子替换。恢复不重放已完成工具操作，不把观察事件当作执行证据。

实现合同见 [NATIVE_EXECUTION.md](NATIVE_EXECUTION.md)，存储见 [CURRENT_STATE_STORAGE.md](CURRENT_STATE_STORAGE.md)，数据兼容边界见 [DATA_MIGRATIONS.md](DATA_MIGRATIONS.md)。
