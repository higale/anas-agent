# 面板框架

帮助、文件变更、子 Agent 和插件共用同一个页面注册表、侧栏布局协议和独立窗口。每个打开的面板只有一个 `WebContentsView`；切换位置移动这个实例，不重载页面。关闭面板销毁视图，不取消 Agent 任务。

## 职责

- `src/shared/panels.ts`：面板描述、项目／会话上下文及窗口协议。
- `src/shared/panelToolbar.ts`：通用标题栏状态、图标操作和参数校验；内置与插件页面共用 preload 实现。
- `src/main/panels/panelViews.ts`：页面所有权、串行移动、位置冲突、目标准备、失败回滚和销毁。通过页面定义接入内容，不负责插件业务或 Agent 执行。
- `src/main/panels/panelHost.ts`：内置面板校验、内容服务权限及界面配置快照。
- `src/main/panels/nativeTooltip.ts`：与原生内容重叠的提示浮层；鼠标穿透、不抢焦点，随所属窗口或提示关闭销毁。
- `src/main/plugins/pluginPanel.ts`：插件页面适配；插件 SDK、后台与协议仍归插件宿主管理。
- `src/renderer/src/ui/agent/useWorkspacePanels.ts`：主进程注册表的标签投影及侧栏选中、展开状态。帮助、插件和文件变更是全局标签；子 Agent 按原项目／会话归组。
- `src/renderer/src/ui/panels/PanelLayouts.tsx`：报告可见插槽、遮挡与尺寸。隐藏不销毁页面。
- `src/renderer/src/panelWindow.tsx`：共用独立窗口标题栏，保留系统按钮，提供移回侧栏操作。
- `src/renderer/src/panelContent.tsx`：内置内容入口，复用原有帮助、差异和活动组件。

## 上下文与数据

文件变更全局只有一个面板，跟随主窗口当前项目和会话，标题显示项目名称。切换上下文保留侧栏／独立窗口位置及展开状态，不主动聚焦；清空旧上下文的运行、文件选择和读取状态。同一上下文中点击消息的改动入口可定位到指定运行。移回侧栏沿用当前上下文。

子 Agent 绑定打开时的项目、会话、运行及子任务 ID，独立窗口不跟随主窗口选择；移回侧栏时恢复原上下文。重新打开已独立显示的内置面板只聚焦原窗口。插件仍允许在不同位置显式打开不同页面实例，移动时不覆盖目标已有实例。

内置页面通过专用 preload 获得有限的展示服务，IPC 校验其来源及上下文。插件页面继续只获得插件宿主接口。主窗口、窗口外壳和内容页的注册与权限相互独立。

配置保存后统一广播已提交快照；差异偏好只提交变更字段，各页面以主进程快照更新，避免跨窗口覆盖。内置页面复用文本右键菜单和窗口缩放服务，操作时解析当前所属窗口。未被内容菜单或编辑器消费的 Esc 才转交所属侧栏，侧栏仅在窄屏抽屉中响应。

活动数据仍来自唯一 Agent runtime、数据库和原有可重放事件订阅。主聊天与面板共享活动投影函数；面板独立分页、读取延迟结果，关闭仅解除订阅。代码审核携带页面显示的上下文标识，主进程拒绝已过期页面的提交；接受后按捕获的项目和会话完成审核。提交期间切换上下文不会将面板或主窗口拉回原会话。

## 生命周期与构建

打开前在应用数据生命周期内完成数据及语言快照准备。侧栏先展开并显示加载状态，页面加载与位置切换独立；加载期间仍可调整尺寸、隐藏、关闭或移到独立窗口。页面就绪后使用最新位置与可见状态，不重新展开或抢占焦点。布局回执、窗口外壳和内容页初始化读取已准备的快照，不等待备份写锁。移动先准备目标再解除源归属；失败保留源页面和最近一次有效布局。恢复、修复和退出关闭全部面板；插件停用只关闭该插件页面；删除会话或项目关闭其相关面板。

preload 使用 electron-vite 的 `isolatedEntries`，每个沙箱入口独立打包，禁止引用共享 chunk。`scripts/verify-main-bundle.cjs` 检查此约束。`patches/electron-vite+5.0.0.patch` 修复该依赖在非 TTY 输出下调用终端光标接口的问题，保证重定向日志和 CI 构建正常。

原生视图位于宿主 DOM 上方；宿主浮层与插槽重叠时暂时隐藏视图。侧栏标签右键菜单使用原生菜单，弹出时保留内容显示；标签提示复用全局 Tooltip。内容自身的菜单和浮层直接在内容页面内显示。标题栏和侧栏拖拽区域使用共享样式，Windows 系统按钮安全区由窗口外壳保留。

Tooltip 不隐藏、移动或缩放内容视图。共享 `GlobalTooltip` 判断提示是否与原生插槽重叠；重叠时将测量结果及共享样式的计算值交给独立透明提示窗口，否则仍在当前 DOM 显示。提示窗口只渲染转义后的文本，不加载脚本或外部资源；按所属窗口缩放定位，关闭、失焦、移动、调整尺寸和页面跳转时回收。

标题栏操作由页面提交完整快照，注册表只保存当前页面的临时状态。窗口外壳的点击回到原内容页执行，完成回执按页面和请求 ID 匹配；移动不重建处理器，关闭和刷新清理操作及快照。执行中禁用同页操作，30 秒超时只报告未响应，保持禁用直到实际完成或页面销毁，不取消插件业务或重试。接口及限制见[插件文档](PLUGINS.md#窗口标题栏)。
