# 面板框架

内置面板使用共享 React 组件，插件使用隔离 iframe。侧栏与独立 BrowserWindow 使用同一套页面协议；页面、业务资源和显示位置分别管理。窗口中没有原生内容视图，菜单、tooltip 和弹窗使用普通 DOM 层级。

## 职责

- `src/shared/panelLifecycle.ts`：稳定面板 ID、唯一页面 ID、恢复上下文、异步命令和有界 JSON 快照。
- `src/main/panels/panelPages.ts`：注册、串行交接、回执、超时、取消、失败恢复和窗口释放。不处理插件业务。
- `src/main/panels/panelHost.ts`：内置上下文、设置快照及 IPC 边界。
- `src/renderer/src/ui/panels/PanelPageHost.tsx`：窗口内的页面集合；切换标签、会话、设置、收起和展开保留已有页面。
- `PluginPage.tsx`：iframe 与私有 MessageChannel；主进程从页面注册记录确定插件身份。
- `BuiltinPanelContent.tsx`：帮助、文件变化、子 Agent 的共享展示组件。
- `PanelViewState.tsx` / `panelViewSnapshot.ts`：选择、展开、滚动、跟随及 Monaco 视图状态；捕获前等待视图检查点；目标重新获取所需数据后确认就绪。隐藏标签的滚动恢复等待有效布局，隐藏期间不覆盖保存的位置。正文、文件列表和 Agent 数据重新订阅原服务。
- `src/renderer/src/panelWindow.tsx`：普通窗口标题栏及页面宿主，保留 Windows 系统按钮和 macOS 红绿灯安全区。

## 身份和交接

同一业务面板只有一个稳定 `panelId`（注册表中为 `viewId`）；每次跨窗口创建不同 `pageId`。插件按插件 ID 和 instanceId 复用，不按位置创建重复实例。需要独立业务实例时由插件分配新的 instanceId。

1. 创建目标容器，侧栏确认可以离开当前设置。尚未冻结源页面。
2. 冻结源页面编辑，异步执行 `prepare`，等待未完成编辑并返回 JSON 状态。
3. 创建目标页面。目标通过 `getContext()` 主动读取完整上下文，恢复状态、订阅资源后显式 `ready()`。
4. 目标 `activate` 接管资源输入；成功后注册表提交新位置，再执行源页面 `dispose({reason:'moved'})`。
5. 失败时销毁目标，源页面 `resume` 恢复控制，保留资源及未保存内容。

命令回执绑定页面和请求 ID，失效回执不会完成新请求。每个面板的移动串行执行；关闭会取消在途交接。SDK 串行执行生命周期，取消的旧处理结束前不执行恢复；原页恢复也失败时保持暂停并报告错误，不伪装成已接管。准备与生命周期命令通常限制 15 秒，目标页面／窗口加载 30 秒，交接后的源页面清理 5 秒。插件必须响应 AbortSignal；有共享资源的插件还须通过后端输入所有权或租约拒绝过期控制请求，不能只靠通知顺序。

状态只允许深度 32、最多 100,000 节点、1 MiB 的 JSON，保存在内存中。密码草稿等敏感内容不得放入 URL、日志或持久化快照。

## 关闭与业务资源

移动释放旧展示页面；关闭面板发送 `dispose({reason:'closed'})`，仍不等同于终止业务。插件的显式“断开／停止”负责结束资源。停用、卸载、备份和应用退出沿用后台管理流程，停止插件后台；Agent 任务和数据继续由唯一运行时管理。

文件变化全局唯一，跟随主窗口当前项目／会话；上下文变化清空旧界面选择，代码审核使用捕获的上下文。子 Agent 绑定原会话和运行，移回侧栏恢复原上下文。帮助保存阅读位置和导航状态。

窗口重载或渲染进程退出会注销该窗口的页面；插件后台资源仍由后台管理，重新打开可按插件协议接入。

独立窗口的 preload 仅提供展示服务，主进程限制其数据访问范围。插件 iframe 没有 Node、preload 或主界面 API。构建只保留主窗口和独立窗口两种沙箱 preload；每个入口独立打包。

## 验证

`panelPages.test.ts` 覆盖交接成功、加载／恢复失败、超时、取消、连续切换及跨窗口回执校验。构建后运行 `node scripts/run-electron-e2e.cjs --panels-only`，使用隔离数据验证真实 React／iframe、草稿、交接期间切换标签后的阅读位置、DOM 菜单与提示及往返移动。RDP 原生会话和真实服务器测试位于插件仓库，宿主不引入 RDP 协议、资源类型或专用恢复路径。
