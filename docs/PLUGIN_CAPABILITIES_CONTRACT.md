# 插件能力边界

按普通工具处理插件工具：区别仅在于执行委托给插件后台。定义、能力选择、取消、结果、效果恢复和对话存储复用宿主已有体系。当前 API 见 [PLUGINS.md](PLUGINS.md)，剩余任务见 [TODO.md](TODO.md)。

## 宿主职责

- 清单静态声明工具，后台显式提供处理器。读取声明不启动后台，也不需要页面身份。
- 项目、子 Agent 独立选择插件贡献；全部模式纳入新增贡献，定制模式下新增条目不选中。
- 运行配置只保存能力选择中的稳定工具 ID；组装时解析当前工具。不额外持久化插件版本、安装代次、内容指纹、工具定义或模型名称映射。
- 工具返回字符串、JSON 或标准文本／Base64 图片块，交给 原生工具结果链路。图片不新增临时文件交付协议、消息格式或存储库。
- Agent 排队、执行槽、后台监督、效果恢复使用现有服务。插件后台只负责调用传输；业务资源互斥由插件实现。
- 取消通过 AbortSignal 通知实际执行者，保留原调用期限、执行槽和真实完成回执。单次取消、超时或处理器无响应均不终止共享后台；无回执时保留在途状态，直到实际完成、进程退出或明确停止插件。3 秒停止宽限期只适用于明确停止后台的收尾；无法确认的写入按现有效果恢复处理。结果校验或保存失败与执行失败分开，不能因此自动重复已经完成的操作。
- 停用、替换、卸载和备份沿用现有后台收尾边界。在途调用不能转入新的后台进程。
- 插件与对话周期独立。工具上下文仅提供本次调用的取消信号、期限及宿主服务，不传递项目／会话／运行身份，不提供对话生命周期回调。业务资源由插件管理并返回资源 ID，后续工具显式引用；对话结束不清理插件业务状态。
- 页面 API 与 API 2 交接保持不变。新增能力不创建第二套 Agent 循环、任务中心或对话快照。
- Skills 使用标准文件和已有技能来源机制；依赖与来源声明放清单，不改写技能正文或复制到用户目录。
- 静态提示词沿用系统上下文组装；只保存必要选择，不为插件另建请求历史和版本锁。
- 能力设置按插件分组，集中选择工具、技能和提示词；项目和子 Agent 按插件选择全部／定制／关闭；未定制项目使用所有已启用的贡献。普通技能分组不影响插件技能，技能页的快捷方式／模型可用性仍是全局上限。插件管理页不重复设置能力开关。普通偏好使用声明式表单和同一份宿主数据，保存校验 revision，失败保留草稿。页面与工具读取当前值，不复制进运行配置。

## 资源与 RDP 边界

- 普通文件和托管进程执行期间保护包资源，占用时明确拒绝覆盖／卸载；不冻结整轮运行。外部和显式脱离托管的进程由用户管理。
- RDP 的连接、画面和输入控制属于插件。模型工具与 UI 调用同一业务服务，宿主不理解服务器、桌面或输入租约。
- RDP 连接、鼠标扫描码手势、展示工具和操作 Skill 已接入。连接只区分显示桌面和后台，不绑定对话；工具输入按单次手势执行，不登记模型控制者。页面交接只校验展示页身份，插件停止或明确断开时清理连接。
- 证书和密码继续使用现有验证及界面；输入支持扫描码、按键名、组合键、鼠标操作及 Unicode 文本，实际字符接收和控件行为由远端应用决定。

本轮按用户确认的当前配置结构实现，不新增老数据兼容或配置升级代码；新增可选字段仍提供默认值，缺失时正常读取。
